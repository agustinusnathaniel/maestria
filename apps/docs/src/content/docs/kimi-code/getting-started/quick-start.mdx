After installation, Kimi Code loads the orchestrator skill and the native system-prompt contribution at session start. Start a new session after installing or updating the plugin.

<Aside type="caution" title="Choose the route that fits the task">
  Delegation adds model work and waiting time. Use [When to Use Maestria](/core/when-to-use/) before
  sending a small task or an expensive model through the full pipeline.
</Aside>

## Delegate One Focused Task

Give the orchestrator a concrete task:

> Use builder to add a JSDoc comment to the add function in src/math.ts.

The orchestrator loads the builder skill and sends the task to Kimi Code's coder subagent. The coder has Write, Edit, and Bash access by default.

## Run a Staged Fix

For a task with an unknown cause and a clear need for review:

> The login flow throws on an empty email. Trace the bug, fix it, and review the fix.

The usual sequence is:

1. diagnose finds and explains the cause.
2. builder applies the confirmed fix.
3. reviewer checks the result.

The orchestrator passes the acceptance evidence and unresolved assumptions between stages. Use direct execution for a small, familiar change.

## Review Several Similar Items

For three or more independent, uniform items, ask for a parallel review:

> Review these five files for security issues: src/auth.ts, src/api.ts, src/db.ts, src/routes.ts, and src/middleware.ts.

Kimi Code can use AgentSwarm to fan out the same reviewer task. The swarm call must be the only tool call in that turn; do not combine it with an exploratory call.

## Plan a Larger Change

Ask planner for ordered milestones before implementation:

> Use planner to draft a migration plan from REST to GraphQL.

The plan should contain phases, success criteria, and rollback points. Give it to the orchestrator for execution or to builder for one phase at a time.

## Native Workflow Commands

Use a namespaced command when you want an explicit route:

```text
/maestria:fein
/maestria:sonar
/maestria:blitz
```

- fein runs the full pipeline.
- sonar stops after research and design.
- blitz skips optional reconnaissance and design when the host permits direct execution.

## Common Problems

| Symptom | First check |
| --- | --- |
| Plugin changes do not appear | Run /reload, then /new |
| Orchestrator writes code directly | Check /plugins info maestria and confirm the session-start skill is orchestrator |
| Reviewer can edit | Persona text is advisory; Kimi permission rules apply to the whole session |
| AgentSwarm is unavailable | Verify Kimi Code v0.38.0 or later |
