This page explains the shared workflow. The repository root [CONTRIBUTING.md](https://github.com/agustinusnathaniel/maestria/blob/main/CONTRIBUTING.md) covers development setup, testing, changesets, and pull requests.

## Canonical Source Workflow

Shared agent prompts, workflow modes, and global rules have one source: packages/core/agent-directives/. Platform packages contain generated projections plus any host-specific adapter code.

Never edit generated agents, skills, commands, rules, or other projection files directly. Your edits will be overwritten by the next sync.

To change shared methodology:

1. Edit the matching Markdown file in packages/core/agent-directives/.
2. Run the sync from the repository root.
3. Check every projection before committing.

```bash
scripts/sync-all
scripts/check-sync
```

The sync configuration for each package adapts names, frontmatter, tool syntax, and host-specific boundaries. Keep those transforms in the platform package. Keep reusable methodology in core.

## Documentation Site

Run the site locally from the repository root:

```bash
pnpm dev
```

After editing docs, build the site to validate MDX and internal links:

```bash
pnpm --filter @maestria/docs build
```
