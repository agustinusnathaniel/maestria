Maestria uses one methodology across several coding-agent platforms, but the runtime behavior is not identical. Choose a native package when you want the host's agents, commands, hooks, permissions, or session features. Choose the portable package when your client supports Agent Plugins v1 and you only need shared skills.

## Choose a package

| If you need... | Start here |
| --- | --- |
| Native agents, hooks, permissions, or session behavior | The package for your coding-agent platform |
| One skills-only package across compatible clients | [`@maestria/agent-plugin`](/agent-plugin/) |
| One command to install and update several native integrations | The [Maestria CLI](/cli/) |
| The shared methodology and role definitions | [Core concepts](/core/agents/) |

## Integration matrix

| Platform | Integration surface | Start with | Boundary to keep in mind |
| --- | --- | --- | --- |
| OpenCode | Native plugin with agents, injected rules, hooks, and agent-level permissions | [OpenCode installation](/opencode/getting-started/installation/) | Runtime permissions come from OpenCode; domain skills are installed separately. |
| Kimi Code | Declarative plugin with skills, native commands, and a system-prompt contribution | [Kimi Code installation](/kimi-code/getting-started/installation/) | Persona rules are advisory unless you add Kimi's session-wide permission rules. |
| Pi | Extension with workflow modes, compaction state, and specialist dispatch through `@gotgenes/pi-subagents` | [Pi and OMP installation](/pi-omp/getting-started/installation/) | Pi subagents inherit parent context, and the peer extension is required for dispatch. |
| Oh My Pi | Extension with workflow modes and native `task()` dispatch | [Pi and OMP reference](/pi-omp/reference/) | OMP's dispatch and lifecycle behavior is different from Pi's. |
| Cursor | Declarative plugin with Task agents, skills, rules, and commands | [Cursor installation](/cursor/getting-started/installation/) | Read-only runtime flags protect selected roles; other methodology rules are advisory. |
| Hermes Agent | Git-based Python plugin with skills, commands, hooks, middleware, and a routing tool | [Hermes installation](/hermes/getting-started/installation/) | Child sessions use a fixed read/research/LLM-only policy; review and landing remain advisory. |
| Claude Code | Native-candidate declarative plugin with agents, skills, commands, and selected `disallowedTools` restrictions | [Claude Code installation](/claude-code/getting-started/installation/) | The package validates locally, but end-to-end runtime behavior is not yet verified. |
| Codex CLI | Native CLI adapter with skills, custom agents, and managed orchestration instructions | [Codex installation](/codex/getting-started/installation/) | Codex desktop parity and hard read-only enforcement are outside this package. |
| Prime Agent | Native-candidate skills-first package with a verified mode-command extension subset | [Prime Agent installation](/prime-agent/getting-started/installation/) | Native `rlm` dispatch and JSON/RPC headless mode remain deferred; end-to-end runtime behavior is not yet verified. |
| Compatible Agent Plugins v1 client | Portable skills-only package | [Portable package](/agent-plugin/) | The current package is pre-release; the client owns discovery, activation, permissions, and session behavior. |
