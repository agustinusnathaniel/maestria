---
title: Privacy
description: 'What this documentation site collects — short version: almost nothing.'
---

This site (`maestria.sznm.dev`) is a static documentation site. There are no accounts, no forms, no comment sections, and no cookies set by the site itself. The site does not collect, store, or process personal data; it serves pre-built HTML, markdown twins of every page, and generated indexes such as `llms.txt` and the sitemap.

Depending on deployment configuration, the site may load privacy-friendly, cookieless analytics: a self-hosted [Umami](https://umami.is) instance and/or Cloudflare Web Insights. These tools measure aggregate usage — page views, referrers, rough device classes — without cookies, without cross-site tracking, and without building individual profiles. They can be disabled entirely in the deployment configuration without affecting any documentation content.

As with any website, the hosting layer (Cloudflare's network) keeps standard request logs for security and operations: your IP address, user agent, requested URL, and timestamp. Maestria's maintainers do not control this logging beyond choosing the host; it is governed by Cloudflare's own policies.

This site links to third-party services — primarily GitHub (source, issues, discussions) and npm (package downloads). Those services operate under their own privacy policies, which apply once you follow a link to them.

If you have a privacy question about this site or the Maestria project, open an issue on [GitHub](https://github.com/agustinusnathaniel/maestria/issues); see [Contact](/contact/) for what to include. Background on the project itself is on the [About](/about/) page.
