---
title: Privacy
description: 'What this documentation site collects - short version: almost nothing.'
---

This site (`maestria.sznm.dev`) is a static documentation site: no accounts, no forms, no comment sections, and no cookies set by the site itself. It does not collect, store, or process personal data; it serves pre-built HTML, markdown twins, and generated indexes such as `llms.txt` and the sitemap.

Depending on deployment configuration, the site may load cookieless, privacy-friendly analytics: a self-hosted [Umami](https://umami.is) instance and/or Cloudflare Web Insights. These measure aggregate usage - page views, referrers, rough device classes - without cookies, cross-site tracking, or individual profiles, and can be disabled in the deployment configuration without affecting content.

As with any website, the hosting layer (Cloudflare's network) keeps standard request logs for security and operations: your IP address, user agent, requested URL, and timestamp. Maestria's maintainers do not control this logging beyond choosing the host; Cloudflare's own policies govern it.

This site links to third-party services, primarily GitHub and npm. Those services operate under their own privacy policies, which apply once you follow a link to them.

If you have a privacy question about this site or the Maestria project, open an issue on [GitHub](https://github.com/agustinusnathaniel/maestria/issues); see [Contact](/contact/) for what to include. Background on the project itself is on the [About](/about/) page.
