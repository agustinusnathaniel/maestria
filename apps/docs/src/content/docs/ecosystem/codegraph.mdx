## What It Is

CodeGraph is a local-first code intelligence tool. It parses your codebase into a queryable SQLite knowledge graph, and the index auto-syncs via a file watcher as you edit.

Indexing and queries run locally and need no API keys. By default CodeGraph sends anonymous usage statistics; turn them off with `codegraph telemetry off`. CodeGraph exposes an MCP server with a `codegraph_explore` tool that agents query instead of running grep or read loops. One call returns the verbatim source of relevant symbols, the call path among them, and a blast-radius summary.

It supports 20+ languages including TypeScript, JavaScript, Python, Go, Rust, Java, and C#.

## Why Use It Alongside maestria

A single `codegraph_explore` call can stand in for a series of grep and read operations during reconnaissance; CodeGraph publishes its own benchmark of the tool-call and token savings. maestria supplies the workflow; CodeGraph handles codebase access within it.

## Installation

Three options:

1. **npm global install:** `npm install -g @colbymchenry/codegraph@latest`
2. **Run without install:** <AllPackageManagers type="dlx" pkg="@colbymchenry/codegraph@latest" />
3. **Install script:** `install.sh` (macOS and Linux) or `install.ps1` (Windows), as shown in the GitHub README

## Quick Start

Run `codegraph init` in your project root. Once indexed, agents can query CodeGraph via its MCP server.
