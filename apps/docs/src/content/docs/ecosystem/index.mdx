Maestria works great on its own, but these complementary tools can enhance your experience when paired with Maestria-powered agents.

These tools are independent projects with their own communities and maintainers. Maestria does not depend on any of them; they are optional enhancements.

<CardGrid>
  <LinkCard
    title="CodeGraph"
    description="Local-first code intelligence that builds a SQLite knowledge graph of your codebase. A natural companion for AI coding agents using structured workflows."
    href="/ecosystem/codegraph/"
  />
  <LinkCard
    title="RTK"
    description="A CLI proxy that filters command output to save 60-90% tokens. Popular companion for AI coding agents, reduces context burn from verbose tool output."
    href="/ecosystem/rtk/"
  />
  <LinkCard
    title="OpenCode Goal Plugin"
    description="Codex-style long-running goal mode for OpenCode: a /goal command, persistent goal state, and idle continuation. Complements Maestria's orchestrator continuation policy."
    href="/ecosystem/opencode-goal-plugin/"
  />
  <LinkCard
    title="Portable Agent Plugin"
    description="Agent Plugins v1 package that delivers Maestria's methodology as standard Agent Skills for compatible clients."
    href="/ecosystem/agent-plugin/"
  />
</CardGrid>
