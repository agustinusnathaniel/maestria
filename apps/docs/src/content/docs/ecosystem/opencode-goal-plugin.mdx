OpenCode Goal Plugin is an independent project under the MIT license, published on npm as `@prevalentware/opencode-goal-plugin` and maintained by prevalentWare. It is not part of maestria. It is currently pre-1.0 (0.1.x).

## What It Is

OpenCode Goal Plugin adds Codex-style long-running goal mode to OpenCode: a `/goal` slash command (with `/pause_goal` and `/resume_goal`), persistent per-session goal state with history and checkpoints, optional idle continuation, and a terminal UI goal indicator. A session keeps working toward one explicit objective until it is complete, blocked, or cleared.

## Why Use It With maestria

maestria's orchestrator follows a continuation policy: the session owns progress toward one explicit outcome until it reaches its terminal artifact. The plugin expresses a similar contract at the runtime level.

Goal lifecycle tools belong to the host runtime; maestria's directives stay host-agnostic, and maestria neither requires nor activates this plugin.

## Installation

Current `@maestria/opencode` releases target OpenCode V2. The plugin's README documents V2 support as beta: add the package to `plugins` in `opencode.json`, and to `~/.config/opencode/cli.json` for the sidebar and command palette:

```json
{
  "plugins": ["@prevalentware/opencode-goal-plugin"]
}
```

On OpenCode V1, install it globally with:

```bash
opencode plugin -g @prevalentware/opencode-goal-plugin
```

Check the [plugin README](https://github.com/prevalentWare/opencode-goal-plugin#readme) for the OpenCode 2 builds it supports.

## Quick Start

Start an OpenCode session and set an objective with the `/goal` command.
