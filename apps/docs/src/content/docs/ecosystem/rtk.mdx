RTK is an independent project founded by Patrick Szymkowiak and maintained by the rtk-ai team. The default `rtk` build combines Apache 2.0 code with an engine under the Business Source License (BUSL-1.1); an Apache 2.0-only `rtk-oss` edition is also available. It is not part of maestria.

## What It Is

RTK (Rust Token Killer) is a CLI proxy between your AI coding agent and the shell. It intercepts commands, executes them, and filters or compresses the output before it reaches the LLM context window.

Typical token savings range from 60-90% on command output. RTK supports 100+ commands across git, test runners, build tools, package managers, and cloud CLIs, and includes a dedicated OpenCode plugin.

## Why Use It With maestria

maestria-powered agents run builds, tests, git, and deployment commands through the shell. RTK cuts the token cost of that output, leaving more of the context window for the agent's own work.

## Installation

**macOS (Homebrew):**

```bash
brew install rtk
```

**Windows:** `winget install rtk-ai.rtk`. **Other platforms:** use the install script in the GitHub README.

## Quick Start

Run `rtk init -g` to set up the global integration for Claude Code. Other agents take a flag, for example `rtk init -g --opencode` for the OpenCode plugin or `rtk init -g --codex` for Codex; the RTK README lists every supported agent.
