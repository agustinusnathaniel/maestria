This integration ships in the shared `@maestria/agent-plugins` package. The `cursor` CLI identifier and host-specific installation behavior remain unchanged. The former standalone source package has been removed.

import { Aside } from '@astrojs/starlight/components';
import AllPackageManagers from '@/components/all-package-managers.astro';

`@maestria/agent-plugins` is a declarative plugin: no build step.

## Prerequisites

- **Cursor IDE** and/or **Cursor CLI** (`agent` on `$PATH`)
- Plugin: no Node.js runtime. CLI install below: Node.js and npm

## Install

<AllPackageManagers type="dlx" pkg="maestria@latest" args="install cursor" />

<AllPackageManagers type="dlx" pkg="maestria@latest" args="status" />

The plugin installs to `~/.cursor/plugins/local/maestria`.

<Aside type="caution" title="Enterprise local-plugin gate">
  On Enterprise, `~/.cursor/plugins/local` loads only when an admin enables Allow Local Plugin
  Imports; a same-name marketplace install takes precedence over the local copy. See the [Cursor
  plugin reference](https://cursor.com/docs/reference/plugins.md) and the [plugin
  documentation](https://cursor.com/docs/plugins).
</Aside>

<Aside type="tip" title="Restart Cursor after install">
  Restart Cursor IDE after install so Customize → Plugins picks up the plugin. For CLI, pass
  `--plugin-dir` or use the local plugins directory.
</Aside>

<AllPackageManagers type="dlx" pkg="maestria@latest" args="update cursor" />

## Use with Cursor CLI

```bash
agent --plugin-dir ~/.cursor/plugins/local/maestria
```

## What gets installed

| Path                           | Purpose                  |
| ------------------------------ | ------------------------ |
| `.cursor-plugin/plugin.json`   | Plugin manifest          |
| `agents/*.md`                  | 7 specialist Task agents |
| `skills/orchestrator/SKILL.md` | Dispatcher methodology   |
| `rules/maestria-global.mdc`    | Always-on global rules   |
| `commands/*.md`                | Workflow slash commands  |
