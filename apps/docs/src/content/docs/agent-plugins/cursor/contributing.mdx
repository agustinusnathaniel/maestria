## Ownership

Edit shared methodology in `packages/core/agent-directives/`. Consolidated generation emits isolated complete profiles into `agents/cursor/`, native commands into `commands/cursor/`, and policy and routing into `rules/cursor/`. Its manifest explicitly selects those paths and root utility `skills/`. Generation inputs live under `generation/`; do not edit emitted files.

Keep full role and policy text in native profiles and complete mode and routing context in commands. The two utilities are not role or orchestrator preloads. Preserve native `readonly` metadata and the rule's `alwaysApply` setting.

## Verify

```bash
scripts/sync-all
scripts/check-sync
pnpm --filter @maestria/agent-plugins test
```

Package checks verify selected resources and native metadata. Live Cursor loading and enforcement remain unverified; see [compatibility](/agent-plugins/compatibility/) and the [official plugin reference](https://cursor.com/docs/reference/plugins.md).
