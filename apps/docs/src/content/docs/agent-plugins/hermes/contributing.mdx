For setup and delivery, see the [Contributing Guide](/core/contributing/).

## Ownership

Shared methodology lives in `packages/core/agent-directives/`. The two portable utilities, integration guide, and optional `rules/hermes/context.md` are generated; update canonical directives or generation inputs instead of editing emitted files. Keep root `skills/` limited to utilities. The optional context must remain separate from automatic portable activation.

Hermes has no Maestria Python adapter. Trust, delegation, tool authority, memory, and lifecycle remain Hermes capabilities.

## Verify

```bash
scripts/sync-all
scripts/check-sync
pnpm --filter @maestria/agent-plugins test
```

For a live smoke test, use an isolated Hermes home and install the packed plugin, then inspect plugin and skill discovery. Package checks do not prove host enforcement.
