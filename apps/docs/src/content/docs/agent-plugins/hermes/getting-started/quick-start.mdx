---
title: Quick Start
description: Discover and use maestria's two portable utilities in Hermes.
---

After [installation](/agent-plugins/hermes/getting-started/installation/), enable the plugin and start a fresh session. Ask Hermes to call `skills_list`, then `skill_view` with the discovered qualified name of `handoff` or `iteration-limits`. Hermes derives an `agent-plugin-<slug>-<hash>` namespace, so do not assume `maestria:<skill>`.

| Skill              | Purpose                                                          |
| ------------------ | ---------------------------------------------------------------- |
| `handoff`          | Preserve outcome, constraints, evidence, blockers, and next step |
| `iteration-limits` | Bound repair and review loops with termination conditions        |

## Transfer a Task

```text
Use the installed handoff utility to summarize this task's outcome,
constraints, evidence, blockers, and next step.
```

## Bound a Repair Loop

```text
Use the installed iteration-limits utility to define when this repair
is complete and when repeated failures should be reported as blocked.
```

These utilities provide guidance. Portable installation supplies no specialist, global-rules, fein, sonar, or blitz skills, and does not activate routing or register native profiles or workflow commands. They do not restrict tools. The former Python adapter's `/mode`, `/mode-clear`, and workflow commands are retired.

## Optional Methodology Context

To add full routing, policy, and mode guidance manually, follow [the host-context setup](/agent-plugins/hermes/getting-started/installation/#optional-manual-host-context). A portable install alone does not load that context. Even with manual guidance, native agent registration and delegation remain Hermes capabilities.

maestria adds no Python adapter, memory provider, background schedule, OpenCode bridge, or permission gate. See [compatibility](/agent-plugins/compatibility/) for dated discovery evidence and its limits.
