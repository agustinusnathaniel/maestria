---
title: Utility Skills
description: The two Maestria utilities available through Hermes portable skill discovery.
---

The consolidated plugin exposes two utilities through Hermes `skills_list` and `skill_view`. Discover their qualified names before loading them: Hermes derives an `agent-plugin-<slug>-<hash>` namespace, so do not assume `maestria:<skill>`.

| Skill              | Purpose                                                          |
| ------------------ | ---------------------------------------------------------------- |
| `handoff`          | Preserve outcome, constraints, evidence, blockers, and next step |
| `iteration-limits` | Bound repair and review loops with termination conditions        |

Portable installation does not supply specialist, orchestrator, global-rules, fein, sonar, or blitz skills. It does not activate routing or register native profiles or workflow commands. The former Python adapter's `/mode`, `/mode-clear`, and workflow commands are retired.

For optional manual routing and policy configuration, see [installation](/agent-plugins/hermes/getting-started/installation/#optional-manual-host-context). This uses the host's context loader and is separate from portable plugin activation.
