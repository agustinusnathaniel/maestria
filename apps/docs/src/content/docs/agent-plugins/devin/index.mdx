Devin reads `@maestria/agent-plugins` through `.devin-plugin/plugin.json`. The package supplies complete conventional root agent profiles and always-on policy and routing in root `AGENTS.md`. The manifest's supported skills selector array adds two utilities and three Devin-specific workflow compatibility exports.

## Install

Stage a validated package:

<AllPackageManagers type="dlx" pkg="maestria@latest" args="plugin install" />

Install the printed directory through Devin:

```bash
devin plugins install --local /path/to/staged-plugin
devin plugins info maestria
```

`--local` links the directory on this machine. For personal plugin sync to cloud sessions and other devices, use the repository subdirectory:

```bash
devin plugins install agustinusnathaniel/maestria#packages/agent-plugins
```

Changes apply to new sessions. Use **Reindex plugins** on Devin's Customize page to refresh the web listing. See the [official installation formats](https://docs.devin.ai/cli/extensibility/plugins/overview) and [Customize guide](https://docs.devin.ai/product-guides/plugins).

## Use

| Skill entry point             | Purpose                                 |
| ----------------------------- | --------------------------------------- |
| `/maestria:fein <goal>`       | Full route with independent review      |
| `/maestria:sonar <goal>`      | Research and stop before implementation |
| `/maestria:blitz <goal>`      | Smallest safe implementation route      |
| `handoff`, `iteration-limits` | Context transfer and bounded repair     |

The three workflow exports carry complete mode, router, and policy. They live outside root `skills/`, keeping portable discovery limited to utilities. There are no role, orchestrator, or global-rules skill facades, and the manifest declares no undocumented command selector.

In local CLI and Desktop sessions, dispatch native specialist profiles through Devin's subagent controls. Each profile includes complete role and global policy; carry task constraints and evidence in the handoff. Root `orchestrator` is a dispatcher profile, not a primary-agent override.

## Limits

Native plugin agents load in local CLI and Desktop sessions, not cloud sessions. Personal plugins can supply the selected skills and policy to cloud sessions, but their presence does not add native plugin subagents there. Root profiles provide advisory guidance and make no tool-denial or sandbox claim. No executable adapter, hooks, MCP server, or automation ships here. Live Devin loading remains unverified; package checks establish shipped resources only.
