title: Quick Start
description: Route work with Codex's companion-installed native agents and global instructions.
---

Install with `npx maestria install codex` using the [CLI setup](/agent-plugins/codex/getting-started/installation/), then start a new Codex session. The companion installation adds complete global routing and policy instructions plus seven native agents. A marketplace-only install supplies the two utilities and needs the companion installation for this workflow.

## Route a Task

Describe a concrete outcome and acceptance evidence:

```text
Add rate limiting to the API. Use the smallest safe route and review the result independently.
```

The primary session follows the managed instructions and delegates when useful. Maestria does not replace Codex's primary agent, approvals, or sandbox.

## Choose a Mode

Use natural-language mode keywords, which are case-insensitive and per-turn:

```text
FEIN: Add rate limiting to the API.
SONAR: Trace authentication and report findings without editing.
BLITZ: Fix the known typo and run the relevant check.
```

FEIN requests the full route, SONAR stops before implementation, and BLITZ skips optional ceremony while retaining safeguards and required review. The managed instructions also recognize explicit mode markers such as `[MODE: sonar]`. These modes are instruction entry points, not installed skills or Codex slash commands.

## Dispatch a Native Specialist

Ask Codex to use `agent_type: "maestria-adventurer"` to trace a module. The other native types are `maestria-architect`, `maestria-builder`, `maestria-diagnose`, `maestria-planner`, `maestria-reviewer`, and `maestria-writer`.

Each TOML profile embeds complete role and global policy. Pass the concrete goal, file scope, constraints, and evidence to the child. Use a separate `maestria-reviewer` after implementation; research and review profiles retain Codex's native read-only sandbox.

## Plugin Utilities

Marketplace installation exposes `$maestria:handoff` and `$maestria:iteration-limits`. For example:

```text
$maestria:handoff Summarize this task's outcome, constraints, evidence, and next step.
```

There are no specialist, global-rules, or mode skill facades. See the [desktop setup](/agent-plugins/codex/getting-started/desktop/) for the utilities-only marketplace path.
