This setup targets Codex CLI. The same package also supports a skills-only local marketplace install in the [ChatGPT desktop app](/agent-plugins/codex/getting-started/desktop/).

`@maestria/agent-plugins` is a Codex utility-skills plugin with a companion native custom-agent pack. The maestria CLI installs the skills through Codex's plugin manager, the `maestria-*.toml` agent roles under `$CODEX_HOME/agents/`, and a marked orchestration block in `$CODEX_HOME/AGENTS.md` or `$CODEX_HOME/AGENTS.override.md`. It preserves unrelated instructions and does not write `config.toml`, register models, add MCP servers, or install hooks.

<Aside type="tip" title="CLI verification scope">
  Package/unit tests and builds cover the consolidated companion installer and profile payload. The
  2026-08-26 marketplace smoke used Codex CLI `0.145.0` and the former standalone package. No fresh
  CLI host E2E covers the consolidated archive. The desktop guide follows documented
  local-marketplace setup; desktop runtime behavior also remains unverified.
</Aside>

## Prerequisites

- Codex CLI with plugin and native custom-agent support. The inspected AgentPlugin loader is version `0.153.4`; other versions require rechecking.
- Node.js >=22.12.0 and npm on `PATH`. Direct Codex marketplace installation follows Codex's own prerequisites.

## Install through maestria

<AllPackageManagers type="dlx" pkg="maestria@latest" args="install codex" />

The CLI stages a local marketplace at `~/.cache/maestria/codex-marketplace`, then delegates installation to Codex (`codex plugin marketplace add`, `codex plugin add maestria@maestria`). Codex plugins cannot ship agents, so it also copies the bundled `agents/maestria-<role>.toml` roles to `$CODEX_HOME/agents/` and updates the managed global orchestration instructions. The plugin cache and enabled state belong to Codex.

## Verify the installation

<Steps>

1. **Check the host status**

   <AllPackageManagers type="dlx" pkg="maestria@latest" args="check codex" />

2. **List the installed plugin**

   ```bash
   codex plugin list --json
   ```

   Look for `maestria@maestria` with `installed: true`.

3. **Start a fresh Codex session**

   Plugin discovery is session-sensitive. Confirm `$maestria:handoff` and `$maestria:iteration-limits` are available.

4. **Exercise the integration**

   Ask Codex to handle a meaningful task without a skill prefix and confirm the primary session follows the orchestration guidance. Try `SONAR: trace authentication without editing`, then a separate implementation task with independent native reviewer delegation.

5. **Verify native agent installation**

   Confirm `~/.codex/agents/maestria-*.toml` files exist (or the equivalent `$CODEX_HOME/agents/` directory). Ask Codex to delegate with `agent_type: "maestria-builder"` and use `maestria-reviewer` for independent review. The adventurer, architect, planner, and reviewer roles use `sandbox_mode = "read-only"`.

</Steps>

## Update and remove

<AllPackageManagers type="dlx" pkg="maestria@latest" args="update codex" />
<AllPackageManagers type="dlx" pkg="maestria@latest" args="uninstall codex" />

Codex CLI does not expose a separate plugin update command in the supported surface. The maestria CLI refreshes the staged npm package, removes and re-adds `maestria@maestria`, then refreshes the native agent TOMLs while preserving user model settings. Exact version pinning is not supported through `npx maestria update codex --version ...`. Uninstall removes only the maestria-managed agent files and marked orchestration block; existing Codex instructions and unrelated agent files remain untouched.

## Direct Codex CLI plugin installation

The repository also exposes a native Codex marketplace entry backed by the published npm package:

```bash
codex plugin marketplace add agustinusnathaniel/maestria
codex plugin add maestria@maestria
```

`codex plugin add` expects a `PLUGIN@MARKETPLACE` selector, not a bare npm package name. Direct installation installs only the plugin and its `handoff` and `iteration-limits` utility skills: it does not copy the native agent TOMLs or modify global `AGENTS.md`. Use `npx maestria install codex` for the full native-agent and automatic-orchestration setup.

Codex `0.153.4` discovers the conventional root `skills/` directory. Its AgentPlugin loader ignores the overlay skills selector, so that selector cannot turn native commands or agents into skills. The `.codex-plugin/plugin.json` compatibility manifest supplies presentation metadata. Direct plugin installation does not add native agent TOMLs or managed global instructions.

See the separate [Codex desktop setup](/agent-plugins/codex/getting-started/desktop/) to install the skills through a personal npm marketplace.
