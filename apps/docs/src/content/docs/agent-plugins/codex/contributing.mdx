## Ownership

Canonical directives live in `packages/core/agent-directives/`. Consolidated generation emits complete Codex agent TOMLs in `agents/codex/` and a complete global instruction resource in `rules/codex/`. The companion CLI installs those resources and preserves unrelated instructions and user model settings. Manifest inputs and native metadata templates live under `generation/`.

Keep root `skills/` limited to `handoff` and `iteration-limits`. Codex `0.153.4` discovers that conventional root and ignores the overlay skills selector. Do not recreate roles, commands, or global policy as Codex skill facades. Native read-only sandbox metadata belongs in agent TOMLs.

## Verify

```bash
scripts/sync-all
scripts/check-sync
pnpm --filter @maestria/agent-plugins test
pnpm --filter maestria test
```

Package tests cover resource completeness and companion installation. The loader source establishes root skill discovery; it does not establish live model behavior or desktop runtime parity. See the [compatibility matrix](/agent-plugins/compatibility/).
