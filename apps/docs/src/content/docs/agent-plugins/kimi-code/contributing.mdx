## Ownership

Canonical methodology lives in `packages/core/agent-directives/`. Consolidated generation emits seven complete native profiles into `agents/kimi-code/`, complete commands into `commands/kimi-code/`, and complete session instructions into `rules/kimi-code/bootstrap.md`. Manifest and metadata inputs live under `generation/`; emitted resources are generated.

## Preserve the Host Contract

The Kimi manifest explicitly selects `agents`, `commands`, root utility `skills`, and `systemPromptPath`. It does not use `sessionStart.skill`, `skillInstructions`, or built-in persona mappings. Keep the bootstrap below the documented 32 KB limit. Preserve `tools`, `disallowedTools`, and `subagents` metadata. Do not add a model field that Kimi's plugin-agent format does not support.

## Verify

```bash
scripts/sync-all
scripts/check-sync
pnpm --filter @maestria/agent-plugins test
```

Package checks validate complete paths, native metadata, and bootstrap size. They do not establish live host loading or shell isolation. See [compatibility](/agent-plugins/compatibility/) and the [official plugin-agent contract](https://www.kimi.com/code/docs/en/kimi-code-cli/customization/plugins.html#plugin-agents).
