## Ownership

Canonical role, mode, routing, and policy text lives in `packages/core/agent-directives/`. The consolidated generation pipeline emits complete Claude Code profiles into `agents/claude-code/` and complete native workflow commands at the package root. Root `skills/` contains only `handoff` and `iteration-limits`. Edit generation inputs or canonical directives, then regenerate; do not edit emitted resources.

The Claude manifest explicitly selects its seven profiles and three commands. Preserve native `model: inherit` and the read-only roles' `disallowedTools` metadata. Profiles must work without skill preloads.

## Verify

```bash
scripts/sync-all
scripts/check-sync
pnpm --filter @maestria/agent-plugins test
claude plugin validate ./packages/agent-plugins --strict
```

Strict validation confirms package structure and frontmatter. The offline host fixture covers the tested Agent tool and child-context behavior; it does not establish model judgment, shell isolation, account sync, Cowork, or Desktop behavior. See the [compatibility matrix](/agent-plugins/compatibility/).
