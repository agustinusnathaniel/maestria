This integration ships in the shared `@maestria/agent-plugins` package. The `claude-code` CLI identifier and host-specific installation behavior remain unchanged. The former standalone source package has been removed.

import { Aside, Steps } from '@astrojs/starlight/components';

`@maestria/agent-plugins` is a declarative Claude Code plugin: a `.claude-plugin/plugin.json` manifest that lists the seven shared `agents/<role>.md` profiles and three shared `commands/*.md` workflows explicitly (Claude rejects directory agent selectors), and the two utility skills. No build step or runtime code is required.

See the host-side model in the [Claude Code plugin components guide](https://code.claude.com/docs/en/plugins/components).

<Aside type="caution" title="CLI evidence is scoped">
  Strict plugin validation passes on Claude Code `2.1.295`. An offline fixture (2026-10-12) loaded
  the reviewer from the shared `agents/reviewer.md` with Write and Edit unavailable and the full
  role and global policy in the child context. It does not test model judgment, shell-mediated
  editing, every specialist, other CLI versions, account plugin sync, Cowork, or Desktop Code. See
  the [host verification
  record](https://github.com/agustinusnathaniel/maestria/blob/main/docs/plugin-host-verification.md).
</Aside>

## Prerequisites

- **Claude Code** with the `claude` CLI on `PATH` - required for the CLI install and validation paths below.
- **Node.js and npm** - required when installing through `maestria install claude-code`.
- **Node.js and pnpm** - only needed to regenerate files from the canonical core directives.

## Persistent installation through the maestria CLI

<AllPackageManagers type="dlx" pkg="maestria@latest" args="install claude-code" />

The CLI downloads `@maestria/agent-plugins` from npm, stages it in a local marketplace under `~/.cache/maestria/`, and delegates installation to Claude Code. Plugin state and scope stay in the host runtime.

Check, update, or remove the installation with:

<AllPackageManagers type="dlx" pkg="maestria@latest" args="status" />
<AllPackageManagers type="dlx" pkg="maestria@latest" args="update claude-code" />
<AllPackageManagers type="dlx" pkg="maestria@latest" args="uninstall claude-code" />

Claude Code's marketplace update path selects the latest package. Exact version pinning is not available through `maestria update claude-code --version`.

## Claude Code Desktop setup

Claude Code Desktop shares configuration with the CLI for local sessions. For an existing CLI installation, open a **local** or **SSH** Code session in Desktop; the plugin manager can show, enable, disable, or uninstall plugins from configured marketplaces.

To install from the Desktop UI, first add the maestria marketplace in the CLI:

```bash
claude plugin marketplace add agustinusnathaniel/maestria
```

Then, in a local or SSH Code session, click **+** beside the prompt, choose **Plugins**, select **Add plugin**, and install `maestria` from the configured marketplace. Verify it in the same menu or with `/plugin` in the CLI. The Desktop plugin browser is unavailable in cloud sessions, and plugins installed from Desktop are not available there. See the [Claude Code Desktop guide](https://code.claude.com/docs/en/desktop).

## Local validation (no install)

From a checkout of this repository:

```bash
claude plugin validate ./packages/agent-plugins --strict
```

`--strict` treats warnings as errors and is the recommended CI check. A clean run prints `✔ Validation passed`.

## Verify Installation

<Steps>

1. **Start a session with the plugin loaded**

   `--plugin-dir` is session-only and can be passed multiple times to load several plugins:

   ```bash
   claude --plugin-dir ./packages/agent-plugins
   ```

2. **Confirm the plugin and its components loaded**

   Check the `/plugin` manager and the `/context` Custom Agents tab. Components are namespaced under `maestria`; the identifiers are listed in the table below.

3. **Check the read-only roles**

   `maestria:adventurer`, `maestria:planner`, and `maestria:reviewer` cannot call the `Write` or `Edit` tools (denied via `disallowedTools`).

</Steps>

## What's Inside

| Component | Identifier | Purpose |
| --- | --- | --- |
| Native agents | `maestria:<role>` through the Agent tool | Seven complete specialist profiles |
| Native commands | `/maestria:fein`, `/maestria:sonar`, `/maestria:blitz` | Full, research-only, and fast workflows with complete routing and policy |
| Utility skills | `maestria:handoff`, `maestria:iteration-limits` | Context transfer and bounded repair |

Profiles and commands embed the complete canonical methodology. They do not preload role skills or a global-rules skill. Workflow commands preserve the task arguments.

## Tool Restrictions

Native `disallowedTools: Write, Edit` metadata filters those tools for adventurer, architect, planner, and reviewer. Role and policy text remains guidance; shell-mediated writes are outside this filter. The host controls permission decisions and lifecycle. Profiles set no `model`, so Claude uses the main conversation's model.

Claude Code ignores `permissionMode`, `hooks`, and `mcpServers` agent frontmatter fields for plugin-loaded agents. maestria ships no executable hooks or MCP server and does not modify `CLAUDE.md`.

## Claude Chat and Cowork

The same package includes native commands supported by Claude Code, Desktop Code, and Cowork. Claude account plugins can expose commands and utility skills in Chat; Chat ignores native agents. Cowork supports plugin agents, while maestria's account-sync and Cowork behavior remain unverified. Account plugins sync into Claude Code when signed in with the same account on Claude Code `2.1.273` or later. See [Claude's plugin surface guide](https://support.claude.com/en/articles/13837440-use-plugins-in-claude).

## Uninstalling

Persistent install:

<AllPackageManagers type="dlx" pkg="maestria@latest" args="uninstall claude-code" />

Session-only load: stop passing `--plugin-dir`. The staging directory is safe to remove afterwards:

```bash
rm -rf ~/.cache/maestria/claude-code-marketplace
```

## Direct Claude Code marketplace installation

```bash
claude plugin marketplace add agustinusnathaniel/maestria
claude plugin install maestria@maestria --scope user
```
