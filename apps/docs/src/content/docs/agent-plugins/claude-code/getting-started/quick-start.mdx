After [installation](/agent-plugins/claude-code/getting-started/installation/), start a new CLI session or local Desktop Code session and confirm `maestria` is enabled in the plugin manager.

## Choose a Workflow

```text
/maestria:fein Add rate limiting to the API.
```

| Native command | Use |
| --- | --- |
| `/maestria:fein <goal>` | Full route with reconnaissance, design, implementation, and independent review as needed |
| `/maestria:sonar <goal>` | Research and planning, then stop before implementation |
| `/maestria:blitz <goal>` | Smallest safe route for familiar work, retaining verification and required review |

Each command includes complete routing, mode instructions, and global policy. No mode skill preload is required. For small tasks, read [When to use maestria](/core/when-to-use/) before choosing the full route.

## Delegate to a Specialist

Ask Claude Code to dispatch a native specialist:

```text
Use the maestria:adventurer agent to trace authentication in src/auth/.
Return the relevant paths and findings without editing.
```

The Agent tool identities are `maestria:adventurer`, `maestria:architect`, `maestria:builder`, `maestria:diagnose`, `maestria:planner`, `maestria:reviewer`, and `maestria:writer`. Each profile embeds its complete role and global policy. Give the agent a concrete outcome, constraints, and acceptance evidence.

After implementation, dispatch `maestria:reviewer` independently. Adventurer, architect, planner, and reviewer deny the Write and Edit tools through native metadata; that tool filter does not prevent shell-mediated editing.

## Use a Utility

The two utility skills are `maestria:handoff` and `maestria:iteration-limits`. Use them to transfer context or bound a repair loop. Specialist identities and workflow commands are separate native components.

## Other Claude Surfaces

Claude supports plugin agents in Claude Code and Cowork; Chat ignores agents. Commands and skills can load in Chat, but the full command workflow needs the host's available delegation capabilities. maestria's live account-sync, Cowork, and Desktop behavior remains unverified. See [installation](/agent-plugins/claude-code/getting-started/installation/) for setup and evidence limits.
