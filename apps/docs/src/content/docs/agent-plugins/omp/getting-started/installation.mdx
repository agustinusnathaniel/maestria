OMP uses the shared `@maestria/agent-plugins` package. It supplies complete native task profiles, workflow commands, an always-apply policy and routing rule, and two utility skills. OMP owns plugin activation, task execution, permissions, and session behavior.

## Install

<Steps>

1. Stage and install the package with the Maestria CLI:

   <AllPackageManagers type="dlx" pkg="maestria@latest" args="install omp" />

2. Confirm OMP registered the package:

   ```bash
   omp plugin list
   ```

3. Start a new session and confirm `/fein`, `/sonar`, and `/blitz` are available, along with seven specialist task identities and the dispatcher task. Root rule discovery supplies policy and routing.

</Steps>

Direct installation is also available through OMP's package manager:

```bash
omp plugin install @maestria/agent-plugins@latest
```

## Verify Discovery

An isolated OMP 18.4.8 real-CLI probe installed the packed archive, disabled it, reinstalled it, and uninstalled it. It verified eight task profiles, three commands, one always-apply rule, two utilities, exact native bodies, command argument expansion, main-session policy injection, and all eight child-template compositions. Its 41 checks and 52 native file comparisons passed. No inference or actual task spawning ran, so model judgment and runtime permission enforcement remain unverified. See the [host verification record](https://github.com/agustinusnathaniel/maestria/blob/main/docs/plugin-host-verification.md).

## Uninstall

<AllPackageManagers type="dlx" pkg="maestria@latest" args="uninstall omp" />

Or remove the package from OMP:

```bash
omp plugin uninstall @maestria/agent-plugins
```

If the retired `@maestria/omp` executable package is still installed, remove that package separately. Its hooks, interception, review-mode enforcement, goal mirroring, and per-agent model configuration were not carried into this data-only integration.
