---
title: Quick Start
description: Use native maestria workflow commands and task profiles in Oh My Pi.
---

After [installation](/agent-plugins/omp/getting-started/installation/), start a fresh OMP session. Native rule discovery supplies complete routing and global policy. The plugin utilities do not need to be loaded first.

## Run a Workflow

```text
/fein Add rate limiting to the API and review the result independently.
```

Use `/sonar <goal>` for research that stops before editing, or `/blitz <goal>` for familiar work with required safeguards. Each command carries complete mode, routing, and policy instructions.

## Delegate to a Specialist

Ask OMP to use its native `task(agent, task)` tool with `adventurer`, `architect`, `builder`, `diagnose`, `planner`, `reviewer`, or `writer`. For example:

```text
Use the adventurer task profile to trace authentication in src/auth/.
Report paths and uncertainties without editing.
```

Each profile includes full methodology. Supply the task outcome, constraints, and acceptance evidence in the handoff, then use a separate reviewer after implementation.

Profiles inherit the parent model by default. Read-only guidance in the shared profiles is prompt-level only; OMP has no denylist, and runtime tools and enforcement remain OMP controls.

## Use Utilities

`handoff` transfers context and `iteration-limits` bounds repair loops. They are the only portable skills in the package. See the [reference](/agent-plugins/omp/reference/) for native resources and verification limits.
