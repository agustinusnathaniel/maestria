## Native Resources

As of 2026-10-11, the package supplies eight root task profiles, three root commands, one always-apply root rule, and two utility skills for OMP `18.4.8`. The empty `package.json#omp` entry registers this data-only package. See the [host verification record](https://github.com/agustinusnathaniel/maestria/blob/main/docs/plugin-host-verification.md) for the isolated real-CLI install and context-composition results and limits.

| Resource                      | Purpose                                                     |
| ----------------------------- | ----------------------------------------------------------- |
| `agents/orchestrator.md`      | Dispatcher task profile; does not replace the main agent    |
| Seven specialist profiles     | Complete role and global policy for native tasks            |
| `/fein`, `/sonar`, `/blitz`   | Complete native mode commands with routing and policy       |
| `rules/global.md`             | Always-apply global policy and routing for the main session |
| `handoff`, `iteration-limits` | Portable utilities                                          |

Root profiles, commands, and rules are generated from canonical sources. No role, orchestrator, or global-rules skill preload is required.

## Specialist Dispatch

OMP exposes native `task(agent, task)` delegation. Use `adventurer`, `architect`, `builder`, `diagnose`, `planner`, `reviewer`, or `writer` as the agent identity. Profiles embed methodology; task prompts supply the outcome, constraints, and acceptance evidence.

Keep maker and checker independent. By default, root profiles inherit the parent model. Their read-only instructions are advisory, and generic root metadata does not enforce per-role tool denial. OMP owns permissions and task tool exposure. The real-CLI probe verified resource and child-template composition without inference or task spawning; it does not establish model behavior or runtime isolation.

## Workflow Modes

| Command         | Purpose                                               |
| --------------- | ----------------------------------------------------- |
| `/fein <goal>`  | Full route with required independent review           |
| `/sonar <goal>` | Research and stop before implementation               |
| `/blitz <goal>` | Fast route retaining verification and required review |

These are native commands, not skills. The package adds no persistent mode mechanism or session interception.

## Runtime Boundaries

This data-only integration declares no executable extension, task wrapper, lifecycle hook, review interceptor, goal wrapper, automation, or MCP server. The retired `@maestria/omp` runtime's enforcement and session behavior do not carry over. Availability of those features in OMP does not imply Maestria installs them.

For the separate Pi runtime extension, use the [Pi reference](/pi/reference/).
