## Native Resources

As of 2026-10-12, OMP `18.4.8` discovers seven task profiles, three commands, one always-apply rule, and two utility skills from the package, through conventional discovery on both the archive and a git root. `.toml` files are not loaded. The empty `package.json#omp` entry registers this data-only package. See the [host verification record](https://github.com/agustinusnathaniel/maestria/blob/main/docs/plugin-host-verification.md) for the loader probe and its limits.

| Resource                      | Purpose                                                     |
| ----------------------------- | ----------------------------------------------------------- |
| `agents/<role>.md`            | Seven specialist profiles with complete role and policy     |
| `/fein`, `/sonar`, `/blitz`   | Complete native mode commands with routing and policy       |
| `rules/global.md`             | Always-apply global policy and routing for the main session |
| `handoff`, `iteration-limits` | Portable utilities                                          |

Root profiles, commands, and rules are generated from canonical sources and shared with other Markdown hosts. No role or global-rules skill preload is required.

## Specialist Dispatch

OMP exposes native `task(agent, task)` delegation. Use `adventurer`, `architect`, `builder`, `diagnose`, `planner`, `reviewer`, or `writer` as the agent identity. Profiles embed methodology; task prompts supply the outcome, constraints, and acceptance evidence.

Keep maker and checker independent. By default, root profiles inherit the parent model. Read-only is prompt-level only: OMP has no denylist, so the shared `readonly` and `disallowedTools` keys are not enforced. OMP owns permissions and task tool exposure. The loader probe verified resource discovery without inference or task spawning; it does not establish model behavior or runtime isolation.

## Workflow Modes

| Command         | Purpose                                               |
| --------------- | ----------------------------------------------------- |
| `/fein <goal>`  | Full route with required independent review           |
| `/sonar <goal>` | Research and stop before implementation               |
| `/blitz <goal>` | Fast route retaining verification and required review |

These are native commands, not skills. The package adds no persistent mode mechanism or session interception.

## Runtime Boundaries

This data-only integration declares no executable extension, task wrapper, lifecycle hook, review interceptor, goal wrapper, automation, or MCP server. The retired `@maestria/omp` runtime's enforcement and session behavior do not carry over. Availability of those features in OMP does not imply maestria installs them.

For the separate Pi runtime extension, use the [Pi reference](/pi/reference/).
