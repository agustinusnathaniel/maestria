For repository setup, changesets, and pull requests, see the [Contributing Guide](/core/contributing/). Shared workflow and role content is maintained once in the canonical sources and projected into the Agent Plugins package.

## Change Shared Methodology

Use the [Canonical Source Workflow](/core/contributing/#canonical-source-workflow). Do not edit generated profiles, commands, rules, or utility skills directly. Consolidated generation emits complete root profiles, workflow commands, and an always-apply global rule. Preserve package registration through `package.json#omp`; that entry registers data resources, not an executable extension. OMP-specific runtime behavior belongs to the host; this integration declares no runtime adapter.

## Support Evidence

The [host verification record](https://github.com/agustinusnathaniel/maestria/blob/main/docs/plugin-host-verification.md) records the OMP 18.4.8 isolated real-CLI installation, resource loading, command expansion, and context-composition probe. It ran no inference or actual task spawning, and does not establish model judgment or native tool denial.
