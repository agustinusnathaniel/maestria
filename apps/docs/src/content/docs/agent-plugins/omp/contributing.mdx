For repository setup, changesets, and pull requests, see the [Contributing Guide](/core/contributing/). Shared workflow and role content is maintained once in the canonical sources and projected into the Agent Plugins package.

## Change Shared Methodology

Use the [Canonical Source Workflow](/core/contributing/#canonical-source-workflow). Do not edit generated skill files or copied role profiles directly. OMP-specific runtime behavior belongs to the host; this integration declares no runtime adapter.

## Support Evidence

The [host verification record](https://github.com/agustinusnathaniel/maestria/blob/main/docs/plugin-host-verification.md) records the OMP 18.4.8 package discovery probe and its limits. Package discovery does not establish task execution or permission behavior.
