## Unreleased

- Added complete native resources: eight task profiles, three workflow commands, one always-apply global rule, and two portable utilities. The dispatcher task does not replace the primary agent; read-only prompt guidance remains advisory.
- Retired role and workflow skill facades. Parent skill loading is no longer required for native specialist methodology.
- The package includes no executable adapter, hooks, review interceptor, goal wrapper, or MCP server. Remove the retired `@maestria/omp` runtime package separately.
- The OMP 18.4.8 real-CLI probe verifies packed installation lifecycle, native resource bodies, command argument expansion, and main/child context composition. It runs no inference or task spawning and does not establish model judgment or tool denial. See [compatibility](/agent-plugins/compatibility/) and the [shared changelog](/agent-plugins/changelog/).

## 2026-10-10

- Moved OMP to `@maestria/agent-plugins` and grouped its public guides under `/agent-plugins/omp/`. The initial 14-skill, seven-profile layout is superseded by the native resource split above.
