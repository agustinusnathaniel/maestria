## Unreleased

### Native Methodology and Portable Utilities

- Root `skills/` now contains only `handoff` and `iteration-limits`. Roles, policy, routing, and modes have distinct native resources; remove the former role, orchestrator, global-rules, and mode skill invocations from your setup.
- Native profiles embed complete role and policy instructions. Native commands embed complete mode, router, and policy, preserving task arguments. Child methodology no longer depends on role or global-rules skill preloads.
- Claude Code ships seven native specialists and explicit `/maestria:fein`, `/maestria:sonar`, and `/maestria:blitz` commands. Cursor retains native profiles, commands, and an always-apply routing and policy rule.
- Codex marketplace installation supplies only two utilities. Use `maestria install codex` for complete native TOMLs and marked global instructions, then use FEIN, SONAR, and BLITZ keywords or mode markers. Codex `0.153.4` discovers conventional root skills and ignores the overlay skills selector.
- Kimi Code now selects seven native plugin profiles and a complete `systemPromptPath` bootstrap. Built-in coder/explore/plan mappings and session-start skill loading are removed. Native plugin profiles have no per-agent model setting.
- Devin explicitly selects its utilities and three workflow compatibility skills. Root agents and `AGENTS.md` carry complete methodology; native plugin agents remain local CLI/Desktop only.
- ZCode explicitly enables the three native workflow commands. Profiles and commands carry full policy; separate plugin rule-selector support remains unverified.
- OMP now receives eight native task profiles, three commands, one always-apply global rule, and two utilities. The dispatcher task does not override the primary agent. No retired executable enforcement or lifecycle behavior carries over.
- Hermes receives only the two portable utilities. Optional full guidance requires manual import into the host-selected context file; portable activation does not inject it or register specialists. The Python adapter remains retired.
- No executable adapters, lifecycle hooks, recurring automations, or MCP servers ship in this archive. Host availability and package inclusion are documented separately.

## 2026-10-11

- Retained existing public host routes under `/agent-plugins/` and updated installation, quickstarts, capability descriptions, and compatibility boundaries for the native resource split.

## 2026-10-10

- Added Devin and ZCode setup guides and separate Codex CLI and desktop setup. The initial shared role/mode skill layout and thin profile wrappers from this date are superseded by the unreleased migration above.
