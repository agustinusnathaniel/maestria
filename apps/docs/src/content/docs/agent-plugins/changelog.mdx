## 2026-10-10

- Consolidated shared role and workflow methodology into one root skill corpus. Kimi Code now selects those shared skills instead of shipping duplicate specialist skills.
- Added thin host aliases and loader wrappers where native activation needs them. Claude Code profiles preload their role skill and global rules; Cursor retains full role guidance where child skill preloading is not established.
- Documented host-specific resource ownership and runtime limits. OMP uses the portable package and advisory root profiles; the package provides no OMP runtime extension or command layer.
- Grouped public guides for Claude Code, Codex, Cursor, Kimi Code, Hermes, and OMP under `/agent-plugins/<host>/`. Pi remains at `/pi/`, OpenCode at `/opencode/`, and portable package guidance at `/agent-plugins/`.
- Added redirects from the former host-root routes and the combined Pi/OMP routes to their new locations.
