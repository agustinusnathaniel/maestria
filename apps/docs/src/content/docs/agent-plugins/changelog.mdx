## Unreleased

### Native Methodology and Portable Utilities

- Root `skills/` now contains only `handoff` and `iteration-limits`. Roles, policy, routing, and modes have distinct native resources; remove the former role, orchestrator, global-rules, and mode skill invocations from your setup.
- Native profiles embed complete role and policy instructions. Native commands embed complete mode, router, and policy, preserving task arguments. Child methodology no longer depends on role or global-rules skill preloads.
- One shared profile per role (`agents/<role>.md`) and one shared command set (`commands/{fein,sonar,blitz}.md`) now serve Claude Code, Cursor, Kimi Code, ZCode, and OMP. The per-host copies (`agents/claude-code/`, `agents/cursor/`, `agents/kimi-code/`, `commands/cursor/`, `commands/kimi-code/`) and `agents/orchestrator.md` are removed; the always-on rule and commands carry main-session routing. Rules stay per host. Profiles set no `model`.
- Claude Code lists the seven agents and three commands explicitly and ships `/maestria:fein`, `/maestria:sonar`, and `/maestria:blitz`. Cursor adds an always-apply routing and policy rule; its `readonly` metadata is not enforced for plugin-supplied agents (probe on Cursor CLI `2026.10.01`), only for project `.cursor/agents/` copies. `maestria update cursor` carries configured models over from the shared profile or a legacy `agents/cursor/` copy.
- Codex marketplace installation supplies only two utilities. The generated profiles now live at `agents/maestria-<role>.toml` (moved from `agents/codex/`). Use `maestria install codex` to copy them to `$CODEX_HOME/agents/` and add marked global instructions, then use FEIN, SONAR, and BLITZ keywords or mode markers. Codex `0.153.4` discovers conventional root skills and ignores the overlay skills selector.
- Kimi Code uses the shared profiles and commands plus a complete `systemPromptPath` bootstrap. Built-in coder/explore/plan mappings and session-start skill loading are removed. Read-only roles now deny `Write` and `Edit`; the previously shipped `WriteFile` and `StrReplaceFile` names matched nothing in Kimi `v0.38.0`, so read-only was not effective before. Native plugin profiles have no per-agent model setting.
- Devin selects only the two utilities. The three workflow skill exports are removed because Devin has no plugin commands component; trigger modes with keywords such as `fein: <task>`, so `/maestria:fein` no longer exists on Devin. Root agents and `AGENTS.md` carry complete methodology; native plugin agents remain local CLI/Desktop only.
- ZCode selects the shared `agents/` and `commands/` directories (it ignores file lists). Read-only roles now carry `disallowedTools`, which ZCode's source applies by removing `Write` and `Edit` from the subagent's tools; shell access remains. ZCode has no plugin rules component.
- Command files drop the `name` frontmatter key (hosts name commands by filename), and the global rules no longer contain an exclamation mark directly before a backtick, which ZCode and Claude Code commands treat as inline shell expansion.
- OMP receives seven task profiles, three commands, one always-apply global rule, and two utilities through conventional discovery. The former orchestrator task profile is removed. No retired executable enforcement or lifecycle behavior carries over.
- Hermes receives only the two portable utilities. Optional full guidance requires manual import into the host-selected context file; portable activation does not inject it or register specialists. The Python adapter remains retired.
- No executable adapters, lifecycle hooks, recurring automations, or MCP servers ship in this archive. Host availability and package inclusion are documented separately.

## 2026-10-11

- Made `packages/agent-plugins/` directly installable with host manifests beside generated resources. Git and extracted npm archives use the same installation root; development generation inputs remain outside the published archive.
- Retained existing public host routes under `/agent-plugins/` and updated installation, quickstarts, capability descriptions, and compatibility boundaries for the native resource split.

## 2026-10-10

- Consolidated the former standalone declarative host packages into one archive and grouped public guides under `/agent-plugins/<host>/`, retaining redirects from former routes (these host guides were later merged into [Installation](/agent-plugins/installation/) and [Usage](/agent-plugins/usage/)). Pi remains at `/pi/` and OpenCode at `/opencode/`.
- Added Devin and ZCode setup guides and separate Codex CLI and desktop setup. The initial shared role/mode skill layout and thin profile wrappers from this date are superseded by the unreleased migration above.

The release history of the retired standalone host packages is preserved in the [legacy per-host changelog](/agent-plugins/legacy-changelog/). For setup, see [Installation](/agent-plugins/installation/) and [Usage](/agent-plugins/usage/).
