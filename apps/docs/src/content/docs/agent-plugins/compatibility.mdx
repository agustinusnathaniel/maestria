Evidence updated: 2026-10-12. Package validation confirms shipped files and manifest contracts. Loader probes confirm the specific resources and tool schemas they observe. Neither establishes model judgment, live behavior across versions, or enforcement beyond the host's controls. The [host verification record](https://github.com/agustinusnathaniel/maestria/blob/main/docs/plugin-host-verification.md) and [runtime support matrix](https://github.com/agustinusnathaniel/maestria/blob/main/docs/runtime-support-matrix.md) record reproducible methods and limits.

## Current Package Contracts

| Host or surface | Packaged contract | Verification boundary |
| --- | --- | --- |
| Portable Agent Plugins v1 | `handoff` and `iteration-limits`; no MCP server | Package and archive validation. The portable format does not declare native profiles, commands, rules, or hooks. |
| Claude Code | Seven shared specialists (`agents/<role>.md`) and three shared commands, listed explicitly in the manifest; two utilities | `claude plugin validate --strict` passes on `2.1.295`. The offline CLI fixture (`scripts/e2e/claude-skill-preload.ts`, 2026-10-12) loaded the reviewer from the shared profile with Write and Edit unavailable and the full role and global policy in the child context. Model judgment, shell isolation, other roles, account sync, Cowork, Chat, and Desktop behavior remain unverified. |
| Cursor | Seven shared profiles, three shared commands, always-apply rule (`rules/cursor/`); two utilities | Live probe on Cursor CLI `2026.10.01` (2026-10-12): plugin-supplied agents did not enforce `readonly` (a write succeeded), while a project `.cursor/agents/` profile with `readonly: true` was blocked. Other hosts' frontmatter keys do not affect loading. Cursor desktop untested. |
| Codex CLI `0.153.4` | Two marketplace utilities; companion CLI installs complete native TOMLs and marked global instructions | Inspected AgentPlugin loader discovers root `skills/` and ignores the overlay selector. Package and installer tests cover companion payloads. Fresh consolidated-package CLI model E2E unverified. |
| Codex desktop | Two marketplace utilities | Documented personal npm marketplace setup. Native companion and desktop behavior unverified. |
| Kimi Code | Seven shared specialists, three shared commands and `systemPromptPath` bootstrap; two utilities | Documented native contract and package checks. Read-only roles deny `Write` and `Edit`, the tool names registered by Kimi `v0.38.0` and `v2.1.1` source; earlier `WriteFile`/`StrReplaceFile` names matched nothing. Unknown keys are ignored. No per-agent model field. Not live-run: Kimi CLI 2.1.1 needs a Kimi Code subscription. |
| Devin | Root agents and `AGENTS.md`; two utilities. No plugin commands component, so modes are triggered by keywords | Documented conventions and package checks. Devin CLI 3000.11.3 lists 7 profiles, 2 utilities, `AGENTS.md` always on, `rules/global.md` manual, and ignores `.toml` and per-host rules. Native plugin agents are local CLI/Desktop only. No denylist field; read-only is prompt-level. Agent execution not run. |
| ZCode | Seven shared specialists and three shared commands (directory selectors); two utilities | ZCode source: `disallowedTools` removes `Write`/`Edit` from the subagent's tools (shell remains), unknown keys are dropped, only `.md` agents load, and there is no plugin rules component. Not live-run. |
| OMP `18.4.8` | Seven task profiles, three commands, one always-apply rule, two utilities | The real OMP loader probe (`scripts/e2e/omp-plugin-discovery.ts`, 2026-10-12) on archive and git root found 7 agents, 3 commands, 1 rule, and 2 skills; `.toml` files are not loaded. An earlier isolated install lifecycle probe (2026-10-11) covered the previous eight-profile layout. No inference or task spawning ran; no denylist, so read-only is prompt-level. |
| Hermes | Two portable utilities; optional manually configured host context | Documented portable and context-loader contracts. Current two-utility archive smoke requires separate evidence. Context is not automatically imported and does not register specialists. |

OpenCode and Pi retain their separate native packages and guides. The Agent Plugins archive intentionally ships no executable adapter, hooks, automation, or MCP server; this does not imply those capabilities are unsupported by a host.

<Aside type="caution" title="Activation remains client-owned">
  Follow the host's section in [Installation](/agent-plugins/installation/), enable the plugin when
  required, and start a fresh session. Confirm the expected utilities and native resources appear
  before relying on them. A package check or documented setup is not a live runtime compatibility
  result.
</Aside>
