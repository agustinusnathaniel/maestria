Evidence updated: 2026-10-11. Package validation confirms shipped files and manifest contracts. Loader probes confirm the specific resources and tool schemas they observe. Neither establishes model judgment, live behavior across versions, or enforcement beyond the host's controls. The [host verification record](https://github.com/agustinusnathaniel/maestria/blob/main/docs/plugin-host-verification.md) and [runtime support matrix](https://github.com/agustinusnathaniel/maestria/blob/main/docs/runtime-support-matrix.md) record reproducible methods and limits.

## Current Package Contracts

| Host or surface | Packaged contract | Verification boundary |
| --- | --- | --- |
| Portable Agent Plugins v1 | `handoff` and `iteration-limits`; no MCP server | Package and archive validation. The portable format does not declare native profiles, commands, rules, or hooks. |
| Claude Code | Seven complete native specialists and three complete native workflow commands; two utilities | Strict validation and the `2.1.217` offline CLI fixture verify the complete reviewer role and policy in its native child request, absence of Write/Edit, and return of the result. Model judgment, shell isolation, other roles, account sync, Cowork, Chat, and Desktop behavior remain unverified. |
| Cursor | Seven complete isolated profiles, native commands and always-apply policy and routing; two utilities | Package and schema checks. Live loading and enforcement unverified. |
| Codex CLI `0.153.4` | Two marketplace utilities; companion CLI installs complete native TOMLs and marked global instructions | Inspected AgentPlugin loader discovers root `skills/` and ignores the overlay selector. Package and installer tests cover companion payloads. Fresh consolidated-package CLI model E2E unverified. |
| Codex desktop | Two marketplace utilities | Documented personal npm marketplace setup. Native companion and desktop behavior unverified. |
| Kimi Code | Seven native specialists, complete commands and `systemPromptPath` bootstrap; two utilities | Documented native contract and package checks. No per-agent model field. Live loading unverified. |
| Devin | Root agents and `AGENTS.md`; two utilities and three selected workflow compatibility skills | Documented skills selector array and package checks. Native plugin agents are local CLI/Desktop only. Live loading unverified. |
| ZCode | Explicit native specialist and command selectors; two utilities | Documented commands and package checks. Plugin rule-selector support and live loading unverified. |
| OMP `18.4.8` | Eight task profiles, three commands, one always-apply rule, two utilities | An isolated real-CLI probe installed the packed archive, disabled, reinstalled, and uninstalled it. It checked exact native bodies, command arguments, main policy injection, and all eight child-template compositions. No inference or actual task spawning ran; runtime tool denial and model judgment remain unverified. |
| Hermes | Two portable utilities; optional manually configured host context | Documented portable and context-loader contracts. Current two-utility archive smoke requires separate evidence. Context is not automatically imported and does not register specialists. |

OpenCode and Pi retain their separate native packages and guides. The Agent Plugins archive intentionally ships no executable adapter, hooks, automation, or MCP server; this does not imply those capabilities are unsupported by a host.
