This page separates current evidence for the consolidated `@maestria/agent-plugins` package from smoke checks against its former standalone artifact. A pass applies only to the named host, version, package, and behavior. It does not imply support for other components or surfaces.

Evidence updated: 2026-10-10. The [host verification record](https://github.com/agustinusnathaniel/maestria/blob/main/docs/plugin-host-verification.md) and [runtime support matrix](https://github.com/agustinusnathaniel/maestria/blob/main/docs/runtime-support-matrix.md) contain the detailed methods and limits.

## Historical checks against the former artifact

These checks passed against the former `@maestria/agent-plugin` artifact. They do not establish compatibility of the consolidated package.

| Client | Historical result | Scope |
| --- | --- | --- |
| Hermes Agent `0.20.3` | Live smoke passed | Installed and enabled the old npm-packed artifact in an isolated Hermes home; the plugin list and doctor checks passed. |

For clients without a current evidence row, use the [official compatible clients list](https://agent-plugins.org/compatible-clients) for host support and follow the relevant setup guide. Setup instructions do not establish runtime compatibility.

<Aside type="caution" title="Activation remains client-owned">
  Agent Plugins standardizes package shape and component discovery, not each client's UI, account
  state, marketplace setup, enablement controls, or session behavior. After installing, enable the
  plugin if needed and start a new session to confirm its skills appear.
</Aside>
