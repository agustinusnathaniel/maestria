Maestria is a portable AI engineering praxis ecosystem distributed as open-source plugins and a companion CLI. This page lists the real Maestria developer resources and explains what Maestria does not provide, so agents and humans can discover Maestria capabilities without fabrication.

## Maestria CLI Installation and Commands

The primary Maestria entry point is the `maestria` CLI, published as the `maestria` package on npm.

- Install or update for a platform: `npx maestria install <platform>` where `<platform>` is one of `opencode`, `claude-code`, `codex`, `kimi-code`, `cursor`, `pi`, `hermes`, `prime-agent`, or `omp`.
- See [Maestria CLI Getting Started](/cli/getting-started/) for prerequisites and per-platform steps.
- See [Maestria CLI Commands](/cli/commands/) for the full command reference.
- Versioning and distribution: Maestria is versioned via npm and git tags at `https://github.com/agustinusnathaniel/maestria`; use `npx maestria@latest install <platform>` for the newest release or pin to an exact version for reproducible builds.

Maestria CLI execution is local and unauthenticated for installation; publishing is restricted to maintainers via standard npm authentication.

## Maestria Documentation for Agents

Maestria docs at `https://maestria.sznm.dev` are static and agent-friendly. Maestria does not run a hosted API server, so programmatic discovery uses static files:

- **Maestria llms.txt** at `https://maestria.sznm.dev/llms.txt` lists curated Maestria resources including this page, the Maestria When to Use guide, and the Maestria CLI getting started guide. Variants `llms-full.txt` and `llms-small.txt` are also available, with `agents.md` for dedicated agent instructions.
- **Maestria Markdown twins**: every documentation page has a `.md` twin at the same path with `.md` appended, for example `https://maestria.sznm.dev/core/when-to-use.md` mirrors `https://maestria.sznm.dev/core/when-to-use/`. Prefer fetching the `.md` twin when you need raw text for an LLM.
- **Maestria sitemap** at `https://maestria.sznm.dev/sitemap-index.xml` enumerates all public pages, including this Maestria Developer Resources page.

For discovery, this Maestria Developer Resources page is listed in `llms.txt` as `Maestria Developer Resources` at `https://maestria.sznm.dev/developers/overview/` and in the docs sidebar under Developers.

## Maestria CodeGraph MCP Server

The recommended Maestria code intelligence layer is the CodeGraph MCP server, which exposes the `codegraph_explore` tool.

- CodeGraph is an independent project by Colby McHenry, not part of Maestria, but it is the documented companion for Maestria workflows. See [Maestria CodeGraph](/ecosystem/codegraph/) for installation and usage.
- The Maestria CodeGraph MCP server parses a codebase into a local SQLite knowledge graph and answers queries in one call with verbatim source, call paths, and blast radius.
- Upstream docs: `https://colbymchenry.github.io/codegraph/` and `https://github.com/colbymchenry/codegraph`.
- Maestria methodology already references `codegraph_explore` as the first step for reconnaissance; no separate Maestria-hosted MCP server exists.

If you are an agent, call `codegraph_explore` before hand-rolling grep and read loops. The Maestria CodeGraph integration is local-only, with no network required to query.

## Maestria Support and Distribution

Maestria is open source and distributed via public channels:

- **Maestria source repository**: `https://github.com/agustinusnathaniel/maestria` for code, releases, and changelog.
- **Maestria issue tracker**: `https://github.com/agustinusnathaniel/maestria/issues` for bugs, feature requests, and technical support. This is the primary contact surface for Maestria.
- **Maestria on npm**: `https://www.npmjs.com/package/maestria` and scoped packages `@maestria/*` for each platform.
- Updates are published via GitHub releases and npm. Subscribe to releases on GitHub or watch the npm registry; do not expect a Maestria push service.

## What Maestria Does Not Provide

Maestria intentionally does not host centralized services:

- **No hosted Maestria REST API**: there is no `api.maestria.sznm.dev`, no bearer tokens, and no OpenAPI specification for a Maestria backend, because no such backend exists. The documentation site is static, served from `https://maestria.sznm.dev`.
- **No Maestria webhooks**: Maestria does not emit webhooks. Subscribe to Maestria updates via GitHub releases, GitHub webhooks on the Maestria repository, or npm registry hooks and polling via `npm view maestria version`.
- **No Maestria-hosted authentication**: Maestria does not issue API keys or manage identity. Authentication is delegated to GitHub for source and issues, to npm for package publishing, and to each platform host for model provider credentials. The Maestria docs site itself is public and requires no authentication.

If you are looking for an OpenAPI spec, authentication guide, or webhooks for Maestria, the answer is that none are applicable; the honest Maestria developer surface is the CLI, the plugin packages, the docs static files, and the CodeGraph MCP companion described above.
