Maestria is a portable AI engineering praxis delivered as installable plugins and a companion CLI, not a hosted REST service. The Maestria API therefore describes the programmatic surfaces you interact with: the `maestria` CLI, per-platform plugin APIs, and machine-readable documentation endpoints such as the Maestria OpenAPI specification at `/openapi.json`.

This page is the canonical entry point for Maestria API usage. For the formal machine-readable contract, see the [Maestria OpenAPI Specification](https://maestria.sznm.dev/openapi.json).

## Maestria API Overview

The Maestria API has three layers:

1.  **Maestria CLI API** - the `maestria` command wraps per-platform install, update, and configuration behind a single interface. Every subcommand supports `--json` for script consumption and `--help` for local discovery. Start at [CLI Getting Started](/cli/getting-started/) and [CLI Commands](/cli/commands/).
2.  **Maestria Plugin APIs** - each platform adapter (`@maestria/opencode`, `@maestria/claude-code`, `@maestria/codex`, `@maestria/kimi-code`, `@maestria/cursor`, `@maestria/pi`, `@maestria/hermes`, `@maestria/prime-agent`) exposes directives, skills, and commands through the host agent runtime. See the per-platform docs in the sidebar.
3.  **Maestria Documentation API** - static, agent-friendly endpoints for automation: `/openapi.json`, `/llms.txt`, `/sitemap-index.xml`, per-page markdown twins (`<page>.md`), and `/agents.md`. These are described in the Maestria OpenAPI spec.

The Maestria API is versioned through npm and git tags. Install with `npx maestria@latest install <platform>` for the newest contract; pin to an exact version for reproducible builds.

## Maestria OpenAPI Specification

The Maestria OpenAPI 3.0.3 document at `https://maestria.sznm.dev/openapi.json` formalizes the documentation site and CLI as an API, with `info.title: Maestria API` and servers at `https://maestria.sznm.dev`. It documents paths for `/`, `/llms.txt`, `/sitemap-index.xml`, and other discovery endpoints plus component schemas.

Fetch it directly:

```sh
curl -s https://maestria.sznm.dev/openapi.json | jq .info
```

A YAML twin is available at `https://maestria.sznm.dev/openapi.yaml`.

For agents, `llms.txt` lists this page as `Maestria API Documentation` and the spec as `Maestria OpenAPI Specification` for predictable discovery.

## Maestria API Usage Patterns

### Scripted installs

```sh
# Install Maestria for OpenCode and emit JSON for CI
npx maestria install opencode --json | jq .status

# Install for all detected platforms
npx maestria install --all
```

### Discovering Maestria plugin surfaces

Each Maestria plugin package publishes its own README and directive docs. The richest programmatic signal for agents is the CodeGraph MCP server described in [Maestria MCP Server](/developers/mcp/), which lets an agent call `codegraph_explore` once instead of looping grep and read.

## Maestria API Authentication and Rate Limits

The Maestria API for the docs site is unauthenticated and has no rate limits beyond normal CDN protections. Auth is only relevant when interacting with GitHub or npm programmatically; see [Maestria Authentication](/developers/authentication/) for the full model.

## Maestria API Webhooks and Events

Maestria does not emit webhooks as a service. Subscribe to ecosystem events via GitHub and npm mechanisms documented in [Maestria Webhooks](/developers/webhooks/).
