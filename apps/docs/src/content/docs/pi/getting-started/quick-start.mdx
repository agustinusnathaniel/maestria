With `@maestria/pi` installed, start Pi in your project directory:

```bash
pi
```

<Aside type="caution" title="Choose the route that fits the task">
  Review adds model work and waiting time. Use [When to Use maestria](/core/when-to-use/) before
  sending a small task or an expensive, slow model through the full method.
</Aside>

## Run a Task

<Steps>

1. Activate a mode with your task:

   ```text
   fein Add user authentication
   ```

   Or set the mode first:

   ```text
   /fein
   ```

   Pi reports that the mode is set. Describe the task in your next message. The mode stays active until you set another or run `/mode-clear`.

2. Watch the main loop. It investigates, plans, and implements the change itself, loading method skills when needed, and sends meaningful changes to the reviewer before delivery.

3. Run `/maestria-status` to see the mode, reviewer runs, touched files, and recent handoffs.

</Steps>

Use `/sonar` for research that must stop before implementation. Use `/blitz` to skip optional reconnaissance and design when the territory is known, while keeping required validation and review.
