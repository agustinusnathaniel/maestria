Maestria is a set of free, open-source plugins that give AI coding agents a shared engineering workflow: choose a route, delegate focused work, and check the result independently.

## How the Workflow Fits Together

An orchestrator coordinates seven specialists: adventurer (reconnaissance), architect (approach and trade-offs), builder (atomic implementation), diagnose (root-cause analysis), planner (phased plans), reviewer (independent review), and writer (documentation).

Two patterns guide their work:

- **Pipeline composition:** select the needed stages - thinker, worker, verifier - and pass context and evidence between them.
- **Maker/checker split:** the maker produces the result and a separate reviewer checks it. An agent does not approve its own output.

Start with [When to Use Maestria](/core/when-to-use/) to choose direct execution, one specialist, or the full pipeline. [How It Works](/core/how-it-works/) explains the benefits and limits; [Pipeline & Roles](/core/pipeline/) covers sequencing, and [Specialist Reference](/core/agents/) describes each role.

## Install for Your Platform

Native integrations support OpenCode, Kimi Code, Pi, Hermes, Claude Code, Codex CLI, Cursor, Prime Agent, and Oh My Pi. Install one with `npx maestria install <platform>`; use the [CLI guide](/cli/getting-started/) to find the platform ID and prerequisites.

For clients that support Agent Plugins v1, [`@maestria/agent-plugin`](/agent-plugin/) provides portable skills. Run `npx maestria plugin install` to stage the package, then activate it through the client's own installer. Runtime permissions and delegation behavior depend on the host.
