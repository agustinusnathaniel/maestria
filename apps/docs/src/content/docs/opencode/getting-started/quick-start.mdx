Once installed, all agents and rules load automatically in every session.

<Aside type="caution" title="Choose the workflow before choosing the orchestrator">
  Maestria adds coordination and review sessions. For small changes or expensive, slow models,
  direct execution or one specialist is often better. Read [When to use
  Maestria](/core/when-to-use/) first.
</Aside>

## Start a Session

Launch OpenCode as usual. The plugin loads with it.

## Delegate to a Specialist

Call any specialist directly:

```markdown
@adventurer Explore the auth module and trace the login flow.
```

For unfamiliar, multi-file, or high-risk work, hand it to the orchestrator:

```markdown
@orchestrator I need to add rate limiting to the API. Plan and implement it.
```

The orchestrator decomposes the task, delegates to specialists, and integrates the results. It routes work through [thinker, worker, verifier](/core/agents/#orchestration-model) roles: `fein` for the full pipeline, `sonar` for research only, `blitz` for fast implementation. See the [Agent Reference](/core/agents/).

For longer autonomous runs, the independent [OpenCode Goal Plugin](/ecosystem/opencode-goal-plugin/) adds Codex-style goal mode; Maestria neither requires nor activates it.
