`@maestria/opencode` adds an orchestrator, seven specialists, and shared workflow rules to [OpenCode](https://opencode.ai). Install it with the Maestria CLI or add it to your OpenCode configuration.

## Prerequisites

- [OpenCode](https://opencode.ai) CLI (latest version)
- **Node.js 22.12+** - Required for plugin resolution. Earlier versions are not supported.

## Installation via CLI (Recommended)

See the [CLI documentation](/cli/) for more commands and options.

<details>
<summary>Alternative: Manual setup</summary>

Install globally (all projects) or for the current project only:

```bash
opencode plugin @maestria/opencode@latest -g
opencode plugin @maestria/opencode@latest
```

Or add it manually to `~/.config/opencode/opencode.jsonc` (global) or `.opencode/opencode.jsonc` (project-level):

```jsonc
{
  "plugin": ["@maestria/opencode@latest"],
}
```

Restart OpenCode. The plugin auto-installs from npm on session start, and agents and rules are available immediately.

</details>

## Verify Installation

Start a new OpenCode session. The 8 agents are ready for delegation via `@` mention, and the global workflow rules are active in every prompt. Read [When to use Maestria](/core/when-to-use/) before choosing `@orchestrator`.

## Updating

<PackageManagers type="dlx" pkg="maestria" args="update opencode" />

OpenCode does not auto-update plugins. Packages are cached in `~/.cache/opencode/packages/<name>@<version>/`, and the registry is not consulted when a package is already cached. Re-run the install command with the same scope as the original install:

```bash
# If installed globally
opencode plugin @maestria/opencode@latest -g --force

# If installed at project level
opencode plugin @maestria/opencode@latest --force
```

Use `--force` to replace an existing config entry. To force a fresh install from npm, clear the cache first:

```bash
rm -rf ~/.cache/opencode/packages/@maestria/opencode*
```

On Windows, use `Remove-Item -Recurse -Force "$env:USERPROFILE\.cache\opencode\packages\@maestria\opencode*"` (PowerShell) or `rmdir /s /q "%USERPROFILE%\.cache\opencode\packages\@maestria"` (CMD).

<Aside type="tip">
  To pin a specific version, use `"@maestria/opencode@0.7.5"` instead of
  `"@maestria/opencode@latest"`.
</Aside>

## Uninstalling

OpenCode has no built-in command to remove a plugin. The maestria CLI can print the removal steps for your platform: run `maestria uninstall opencode` (see [CLI uninstall](/cli/commands/#uninstall)).

To uninstall manually, remove the entry from the `plugin` array in your OpenCode config file:

```jsonc
{
  "plugin": [
    // Remove or comment out the line below:
    // "@maestria/opencode@latest",
  ],
}
```

Restart OpenCode. The `@maestria/opencode` agents and rules will no longer be available; other OpenCode plugins remain unaffected. You can also delete the cached package with `rm -rf ~/.cache/opencode/packages/@maestria/opencode*`.
