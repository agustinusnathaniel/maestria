## Package Boundary

`@maestria/opencode` pairs a small runtime adapter with methodology generated from `packages/core/agent-directives/`. The adapter loads the generated agent files, parses their frontmatter, and registers them with OpenCode. Platform-specific lifecycle behavior belongs in `packages/opencode/src/`; shared methodology does not.

## Change Methodology

Edit the canonical source, never generated files under `packages/opencode/agents/` or `packages/opencode/rules/`. See the [Canonical Source Workflow](/core/contributing/#canonical-source-workflow). After changing core content:

```bash
scripts/sync-all
scripts/check-sync
pnpm --filter @maestria/opencode test
```

Keep permission changes in `sync.config.ts`, and test them against the generated output.

## Architecture

Record OpenCode-specific boundary decisions in [ADR-OC-001](https://github.com/agustinusnathaniel/maestria/blob/main/docs/adr/opencode/ADR-OC-001-tool-permission-design.md) or the relevant ADR.
