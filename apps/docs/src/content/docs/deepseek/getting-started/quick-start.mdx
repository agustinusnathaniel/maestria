With `@maestria/deepseek` installed, start the web app in your project directory:

```bash
dsh web
```

<Aside type="caution" title="Choose the route that fits the task">
  Delegation adds model work and waiting time. Use [When to Use maestria](/core/when-to-use/) before
  sending a small task or an expensive, slow model through the full pipeline.
</Aside>

## Run a Task

<Steps>

1. Start a new session on the **maestria** preset and describe the task. The orchestrator picks the smallest safe route; no prefix is needed.

2. Watch the delegation. Each specialist runs as a child through its tool, such as `maestria_adventurer` for reconnaissance or `maestria_reviewer` for independent review, and its result returns to the orchestrator.

3. To choose the route yourself, name a mode: ask for `fein` for the full pipeline, `sonar` for research that stops before implementation, or `blitz` for the fast path on familiar work.

</Steps>

You can also ask for a specialist directly:

```text
Use maestria_adventurer to trace the authentication flow and report the relevant files.
```

Adventurer, planner, and reviewer children get no shell or file-editing tools, and architect and diagnose children cannot edit or write files. DeepSeek Harness enforces those filters; everything else follows its sandbox, approvals, and permission presets.
