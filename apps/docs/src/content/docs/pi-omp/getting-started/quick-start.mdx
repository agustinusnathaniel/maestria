With `@maestria/pi` or `@maestria/omp` installed, here is your first session.

<Aside type="caution" title="Activating fein has a real coordination cost">
  Use [When to Use Maestria](/core/when-to-use/) before activating `fein`. Direct execution or a
  single specialist is usually better for small changes, fast iteration, and expensive or slow
  models.
</Aside>

## Start a Session

Open a session in any project directory:

<Tabs syncKey="runtime">
  <TabItem label="Pi">

```bash
pi
```

  </TabItem>
  <TabItem label="OMP">

```bash
omp
```

  </TabItem>
</Tabs>

The extension activates automatically, and the agent applies the orchestrator guidance from the first turn.

## Run a Task

<Steps>

1. Activate a mode with your task:

   ```bash
   fein Add user authentication
   ```

   Or set the mode first:

   ```bash
   /fein
   ```

   Expected: `Mode set to fein. Describe what you'd like to work on.` Then describe the task.

   Mode commands: `/fein` runs the full pipeline, `/sonar` stays research-only, `/blitz` is fast implementation that keeps required validation and review.

2. Watch the pipeline. The orchestrator decomposes the request, dispatches specialists in sequence, and validates each phase before the next begins.

3. Check the session tree with `/maestria-status` to see the current mode, handoff history, and each specialist's contribution.

</Steps>

Slash commands set the mode with a notification. Bare keywords (`fein`, `sonar`, `blitz`) set the mode and attach your task in one message. Exact mode, dispatch, and enforcement behavior is in the [reference](/pi-omp/reference/).
