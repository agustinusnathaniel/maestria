`@maestria/pi` and `@maestria/omp` are extensions that turn the [Pi](https://pi.software) or [Oh My Pi](https://omp.sh) coding agents into disciplined engineering workstations. Each registers 7 specialist subagents, 3 workflow mode commands, and spec-driven orchestration with a single extension entry.

## Prerequisites

- **Pi** or **Oh My Pi (OMP)** CLI - the latest version of your chosen coding agent
- **Node.js 22.12+** - Required for npm-based extension resolution

<Aside type="note">
  **Pi only:** `@maestria/pi` requires the `@gotgenes/pi-subagents` Pi extension for subagent
  dispatch. Install with `pi install npm:@gotgenes/pi-subagents`. OMP has a built-in `task()` tool -
  no additional peer dependency needed.
</Aside>

## Installation

### Pi

The [maestria CLI](/cli/) installs the extension and its peer dependency:

<PackageManagers type="dlx" pkg="maestria@latest" args="install pi" />

### Oh My Pi

```bash
omp install @maestria/omp
```

## Verify Installation

1. Start your platform:

   ```bash
   # Pi
   pi

   # OMP
   omp
   ```

   Expected: the extension loads automatically, and the agent acts as a Maestria dispatcher from the first turn, decomposing tasks and delegating to specialists.

2. List installed extensions:

   ```bash
   # Pi
   pi extensions list

   # OMP
   omp extensions list
   ```

   Expected: `@maestria/pi` or `@maestria/omp` appears in the output.

## Updating

<PackageManagers
  type="dlx"
  pkg="maestria@latest"
  args="update pi"
  comment="Pi (via maestria CLI)"
/>

```bash
# Pi, manual
pi install npm:@maestria/pi@latest

# Or pin a version
pi install npm:@maestria/pi@0.7.5

# OMP
omp install @maestria/omp@latest

# Or pin a version
omp install @maestria/omp@0.5.5
```

Version history is in the [changelog](/pi-omp/changelog/).

## Uninstalling

<PackageManagers
  type="dlx"
  pkg="maestria@latest"
  args="uninstall pi"
  comment="Pi (via maestria CLI)"
/>

```bash
# Pi, manual: the @gotgenes/pi-subagents peer dependency stays for other extensions
pi uninstall @maestria/pi

# Optional: remove the peer dependency if no other extension needs it
pi uninstall @gotgenes/pi-subagents

# OMP
omp uninstall @maestria/omp
```

Restart your platform after updating or uninstalling.
