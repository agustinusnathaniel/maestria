`@maestria/pi` adds the maestria methodology to the [Pi](https://pi.software) coding agent as one extension registering 7 specialist subagents, 3 workflow mode commands, and spec-driven orchestration. [Oh My Pi](https://omp.sh) (OMP) runs the same methodology through the portable `@maestria/plugin` skills with native `task()` dispatch: no maestria-owned executable ships for OMP.

<Aside type="caution">
  **Migrating from `@maestria/omp`?** The native OMP package is retired. Remove it first (`omp
  plugin uninstall @maestria/omp`), then install the plugin below. Session hooks, tool interception,
  review-mode enforcement, goal mirroring, and per-agent model files do not carry over; see the [OMP
  integration
  guide](https://github.com/agustinusnathaniel/maestria/blob/main/packages/plugin/integrations/omp/README.md)
  for the exact boundary.
</Aside>

## Prerequisites

- **Pi** or **Oh My Pi (OMP)** CLI - the latest version of your chosen coding agent
- **Node.js 22.19+** - Required for npm-based extension resolution

<Aside type="note">
  `@maestria/pi` requires the `@gotgenes/pi-subagents` Pi extension for subagent dispatch. Install
  with `pi install npm:@gotgenes/pi-subagents@^21.5.1`. OMP has a built-in `task()` tool - no peer
  dependency needed.
</Aside>

## Installation

<Tabs syncKey="runtime">
  <TabItem label="Pi">

The [maestria CLI](/cli/) installs the extension and its peer dependency:

<AllPackageManagers type="dlx" pkg="maestria@latest" args="install pi" />

  </TabItem>
  <TabItem label="OMP">

The [maestria CLI](/cli/) stages the portable plugin for OMP:

<AllPackageManagers type="dlx" pkg="maestria@latest" args="install omp" />

This runs `omp plugin install @maestria/plugin`. OMP loads the portable skills from the package manifest; no slash commands or session hooks are installed.

  </TabItem>
</Tabs>

## Verify Installation

1. Start your platform: `pi` or `omp`. Expected: on Pi the extension loads automatically and the agent dispatches from the first turn; on OMP load the `global-rules` and `orchestrator` skills in session, then ask the agent to route work through them.

2. List what's installed: `pi list` (Pi) or `omp plugin list` (OMP). Expected: `@maestria/pi` or `@maestria/plugin` appears in the output.

## Uninstalling

<Tabs syncKey="runtime">
  <TabItem label="Pi">

<AllPackageManagers
  type="dlx"
  pkg="maestria@latest"
  args="uninstall pi"
  comment="Pi (via maestria CLI)"
/>

```bash
# The @gotgenes/pi-subagents peer dependency stays for other extensions
pi uninstall npm:@maestria/pi

# Optional: remove the peer dependency if no other extension needs it
pi uninstall npm:@gotgenes/pi-subagents
```

  </TabItem>
  <TabItem label="OMP">

<AllPackageManagers
  type="dlx"
  pkg="maestria@latest"
  args="uninstall omp"
  comment="OMP (via maestria CLI)"
/>

```bash
omp plugin uninstall @maestria/plugin
```

  </TabItem>
</Tabs>

Restart your platform after updating or uninstalling.
