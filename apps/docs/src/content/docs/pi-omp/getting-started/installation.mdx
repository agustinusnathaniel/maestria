`@maestria/pi` and `@maestria/omp` add the Maestria methodology to the [Pi](https://pi.software) and [Oh My Pi](https://omp.sh) coding agents. Each installs as one extension and registers 7 specialist subagents, 3 workflow mode commands, and spec-driven orchestration.

## Prerequisites

- **Pi** or **Oh My Pi (OMP)** CLI - the latest version of your chosen coding agent
- **Node.js 22.12+** - Required for npm-based extension resolution

<Aside type="note">
  **Pi only:** `@maestria/pi` requires the `@gotgenes/pi-subagents` Pi extension for subagent
  dispatch. Install with `pi install npm:@gotgenes/pi-subagents`. OMP has a built-in `task()` tool -
  no peer dependency needed.
</Aside>

## Installation

<Tabs syncKey="runtime">
  <TabItem label="Pi">

The [maestria CLI](/cli/) installs the extension and its peer dependency:

<PackageManagers type="dlx" pkg="maestria@latest" args="install pi" />

  </TabItem>
  <TabItem label="OMP">

```bash
omp install @maestria/omp
```

  </TabItem>
</Tabs>

## Verify Installation

<Steps>

1.  Start your platform:

        <Tabs syncKey="runtime">

      <TabItem label="Pi">

            ```bash
            pi
            ```

          </TabItem>

      <TabItem label="OMP">

            ```bash
            omp
            ```

          </TabItem>

    </Tabs>

        Expected: the extension loads automatically, and the agent dispatches from the first turn, decomposing tasks and delegating to specialists.

2.  List what's installed:

        <Tabs syncKey="runtime">

      <TabItem label="Pi">

            ```bash
            pi list
            ```

          </TabItem>

      <TabItem label="OMP">

            ```bash
            omp plugin list
            ```

          </TabItem>

    </Tabs>

        Expected: `@maestria/pi` or `@maestria/omp` appears in the output.

</Steps>

## Updating

<Tabs syncKey="runtime">
  <TabItem label="Pi">

<PackageManagers
  type="dlx"
  pkg="maestria@latest"
  args="update pi"
  comment="Pi (via maestria CLI)"
/>

```bash
pi install npm:@maestria/pi@latest

# Or pin a version
pi install npm:@maestria/pi@<version>
```

  </TabItem>
  <TabItem label="OMP">

```bash
omp install @maestria/omp@latest

# Or pin a version
omp install @maestria/omp@<version>
```

  </TabItem>
</Tabs>

Version history is in the [changelog](/pi-omp/changelog/).

## Uninstalling

<Tabs syncKey="runtime">
  <TabItem label="Pi">

<PackageManagers
  type="dlx"
  pkg="maestria@latest"
  args="uninstall pi"
  comment="Pi (via maestria CLI)"
/>

```bash
# The @gotgenes/pi-subagents peer dependency stays for other extensions
pi uninstall npm:@maestria/pi

# Optional: remove the peer dependency if no other extension needs it
pi uninstall npm:@gotgenes/pi-subagents
```

  </TabItem>
  <TabItem label="OMP">

```bash
omp plugin uninstall @maestria/omp
```

  </TabItem>
</Tabs>

Restart your platform after updating or uninstalling.
