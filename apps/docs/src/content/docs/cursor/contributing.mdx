## Package Boundary

`@maestria/cursor` generates its agents, skills, and rules from `packages/core/agent-directives/`; the plugin manifest and `sync.config.ts` are hand-authored. Workflow commands under `commands/` are hand-authored; keep them thin (mode marker plus pipeline instructions).

## Editing Methodology

Edit `packages/core/agent-directives/`, never generated files under `agents/`, `skills/`, or `rules/`, and keep Cursor-specific transforms in `sync.config.ts`. Then sync and verify:

```bash
./scripts/sync-all
./scripts/check-sync
pnpm --filter @maestria/cursor test
```
