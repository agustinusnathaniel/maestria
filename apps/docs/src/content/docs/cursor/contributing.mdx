## Package Boundary

`@maestria/cursor` generates its agents, skills, rules, and workflow commands from `packages/core/agent-directives/`; the plugin manifest, `sync.config.ts`, and assets are hand-authored. Keep commands thin (mode marker plus pipeline instructions) by editing the canonical directives, not the generated files.

## Editing Methodology

Edit `packages/core/agent-directives/`, never generated files under `agents/`, `skills/`, or `rules/`, and keep Cursor-specific transforms in `sync.config.ts`. Then sync and verify:

```bash
./scripts/sync-all
./scripts/check-sync
pnpm --filter @maestria/cursor test
```
