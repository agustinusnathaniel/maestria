`@maestria/cursor` is a declarative plugin: no build step.

## Prerequisites

- **Cursor IDE** and/or **Cursor CLI** (`agent` on `$PATH`)
- Plugin: no Node.js runtime. CLI install below: Node.js and npm

## Install

<PackageManagers type="dlx" pkg="maestria@latest" args="install cursor" />

<PackageManagers type="dlx" pkg="maestria@latest" args="status" />

The plugin installs to `~/.cursor/plugins/local/maestria`.

<Aside type="tip" title="Restart required">
  Restart Cursor IDE after install so Customize → Plugins picks up the plugin. For CLI, pass
  `--plugin-dir` or use the local plugins directory.
</Aside>

### Updating

<PackageManagers type="dlx" pkg="maestria@latest" args="update cursor" />

## Use with Cursor CLI

```bash
agent --plugin-dir ~/.cursor/plugins/local/maestria
```

## What gets installed

| Path                           | Purpose                  |
| ------------------------------ | ------------------------ |
| `.cursor-plugin/plugin.json`   | Plugin manifest          |
| `agents/*.md`                  | 7 specialist Task agents |
| `skills/orchestrator/SKILL.md` | Dispatcher methodology   |
| `rules/maestria-global.mdc`    | Always-on global rules   |
| `commands/*.md`                | Workflow slash commands  |
