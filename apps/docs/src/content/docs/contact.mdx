Maestria is maintained on a best-effort basis by a single maintainer, and everything happens in the open on [GitHub](https://github.com/agustinusnathaniel/maestria). There is no email alias, chat, or paid support channel - the repository is the contact surface.

## Report a Bug or Request a Feature

Use [GitHub Issues](https://github.com/agustinusnathaniel/maestria/issues). For a bug report, include:

- The exact command, for example `npx maestria install opencode`.
- The platform and its version, especially for agent-behavior problems: adapters use different host capabilities.
- What you expected and what happened instead.
- Relevant output or logs.

For a feature request, describe the workflow problem you want to solve. Include a proposed implementation if you have one.

## Ask a Question or Contribute

Use the repository's GitHub Discussions for questions so other users can benefit from the answers.

Pull requests are welcome. Pick an open issue, keep changes focused, and follow the [Contributing Guide](/core/contributing/) for adapter, directive, and test conventions. Changes receive independent review before merge.

Response times are not guaranteed; issues are triaged by the maintainer as time allows. For what this project is, see [About](/about/). For questions about data handling on this documentation site, see [Privacy](/privacy/).
