Maestria is maintained on a best-effort basis by a single maintainer, entirely in the open on [GitHub](https://github.com/agustinusnathaniel/maestria); there is no email alias, chat, or paid support channel.

## Report a Bug or Request a Feature

Use [GitHub Issues](https://github.com/agustinusnathaniel/maestria/issues). For a bug report, include:

- The exact command, for example `npx maestria install opencode`.
- The platform and its version, especially for agent-behavior problems: adapters use different host capabilities.
- What you expected and what happened instead.
- Relevant output or logs.

For a feature request, describe the workflow problem you want to solve, with a proposed implementation if you have one.

## Ask a Question or Contribute

Use GitHub Discussions for questions so other users benefit from the answers.

Pull requests are welcome. Pick an open issue, keep changes focused, and follow the [Contributing Guide](/core/contributing/). Changes receive independent review before merge.

Response times are not guaranteed. For what this project is, see [About](/about/); for data handling on this site, see [Privacy](/privacy/).
