@maestria/hermes is a git-based Hermes plugin. It adds 12 skills (9 methodology plus 3 command skills), 7 slash commands, and 10 lifecycle hooks. It also provides an optional `llm_execution` mode footer (enable with `MAESTRIA_MODE_FOOTER=1`) and the optional `opencode_route` tool, which invokes the OpenCode CLI only when you use it.

## Prerequisites

- [Hermes Agent](https://hermes-agent.nousresearch.com)
- Git, for plugin resolution from the repository

## Install

Install through the Maestria CLI:

<PackageManagers type="dlx" pkg="maestria@latest" args="install hermes" />

Or install directly with Hermes, which clones the repository and enables the plugin:

```bash
hermes plugins install agustinusnathaniel/maestria/packages/hermes --enable
```

Verify the native plugin record:

```bash
hermes plugins list
```

`maestria-hermes` should appear as enabled.

## Verify a New Session

Start Hermes and run:

```text
/mode
```

The response should show the active mode. Ask the agent to list the Maestria specialists, then try one focused task. If the mode marker or skills do not appear, restart Hermes and run `hermes plugins list` again.

## Update

<PackageManagers type="dlx" pkg="maestria@latest" args="update hermes" />

Or update the native plugin: `hermes plugins update maestria-hermes`.

## Uninstall

```bash
hermes plugins remove maestria-hermes
```
