---
title: Workflow Skills
description: Maestria workflows available through Hermes skill discovery.
---

The consolidated plugin exposes skills through Hermes `skills_list` and `skill_view`. Discover the qualified names before invocation.

| Skill          | Behavior                                                 |
| -------------- | -------------------------------------------------------- |
| `orchestrator` | Select a proportionate route and coordinate handoffs     |
| `fein`         | Full workflow with required review                       |
| `sonar`        | Research only, then stop                                 |
| `blitz`        | Fast route retaining verification and required review    |
| `handoff`      | Preserve outcomes, evidence, constraints, and next steps |

The former Python commands `/mode`, `/mode-clear`, and native workflow commands are no longer shipped. Skills do not create runtime mode state or tool restrictions.

See [installation](/hermes/getting-started/installation/) for migration and the [specialist reference](/core/agents/) for role responsibilities.
