`maestria` ships maestria's AI engineering methodology to multiple coding agent platforms, using each host's installation flow through one CLI. It also validates and stages portable Agent Plugins for compatible clients.

## Install for Your Host

<AllPackageManagers type="dlx" pkg="maestria@latest" args="install --all" />

Or select one with `maestria install <platform>`. Supported platforms: OpenCode, Kimi Code, Pi, Oh My Pi, Cursor, Hermes, Claude Code, and Codex CLI. See the [command reference](/cli/commands/#install) for platform IDs and package details.

## Stage a portable Agent Plugin

Portable packages are artifacts, not runtime platforms: they do not appear in `maestria status`, and `maestria install` does not activate them. `plugin validate` checks a package, and `plugin install` stages it for a compatible client's own installer. See the [portable Agent Plugin guide](/agent-plugins/).
