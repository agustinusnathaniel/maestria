`maestria` ships Maestria's AI engineering methodology to multiple coding agent platforms, wrapping their native integrations behind one CLI. It also validates and stages portable Agent Plugins for compatible clients.

## Install Native Integrations

Install Maestria for all detected platforms:

<AllPackageManagers type="dlx" pkg="maestria@latest" args="install --all" />

Or select one with `maestria install <platform>`. Supported platforms: OpenCode, Kimi Code, Pi, Oh My Pi, Cursor, Hermes, Prime Agent, Claude Code, and Codex CLI. See the [command reference](/cli/commands/#install) for platform IDs and package details.

### Stage a portable Agent Plugin

Portable packages are artifacts, not runtime platforms: they do not appear in `maestria status`, and `maestria install` does not activate them.

```bash
npx maestria plugin validate ./my-plugin
npx maestria plugin install @maestria/agent-plugin
```

The CLI validates the package, stages it in the Maestria cache, and prints the directory for the compatible client's own installer or local-plugin setting. See the [portable Agent Plugin guide](/agent-plugin/) for the handoff and package boundary.

## Manage Your Installation

Run <AllPackageManagers type="dlx" pkg="maestria@latest" /> to see which supported platforms are on your `PATH`, whether Maestria is installed, and which versions are available.

Then use `install`, `update`, or `configure` to manage an integration; portable packages use `plugin validate` and `plugin install`. All commands support `--json`; runtime platform commands also support `--quiet` to suppress spinner animations for CI.
