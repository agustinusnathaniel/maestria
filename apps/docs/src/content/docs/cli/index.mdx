Maestria ships the same AI engineering methodology to multiple coding agent platforms. Each has its own install commands, update paths, and version management. `maestria` wraps the native integrations behind a single interface, including Claude Code, Codex CLI, and Prime Agent. It also validates and stages the portable Agent Plugins package for clients that support the standard format.

## Why a CLI?

Without the CLI, managing maestria means remembering per-platform commands:

| Platform    | Install                                     | Update                               |
| ----------- | ------------------------------------------- | ------------------------------------ |
| OpenCode    | `opencode plugin @maestria/opencode@latest` | Re-run with `--force`                |
| Kimi Code   | `maestria install kimi-code`                | `maestria update kimi-code`          |
| Pi          | `pi install npm:@maestria/pi`               | `pi install npm:@maestria/pi@latest` |
| Prime Agent | `maestria install prime-agent`              | `maestria update prime-agent`        |
| Claude Code | `maestria install claude-code`              | `maestria update claude-code`        |
| Codex CLI   | `maestria install codex`                    | `maestria update codex`              |

With the CLI, one command does it all:

<AllPackageManagers type="dlx" pkg="maestria@latest" args="install --all" />

No more context-switching between platform CLIs. No more hunting through READMEs for the right command.

### Stage a portable Agent Plugin

Portable packages use a separate command namespace because they are artifacts, not runtime platforms. They do not appear in `maestria status` and are not activated by `maestria install`.

```bash
npx maestria plugin validate ./my-plugin
npx maestria plugin install @maestria/agent-plugin
```

The CLI validates the package, stages it in the Maestria cache, and prints the directory for the compatible client's own installer or local-plugin setting. See the [portable Agent Plugin guide](/agent-plugin/) for the handoff and package boundary.

## How It Works

1. **Run <AllPackageManagers type="dlx" pkg="maestria@latest" />** - no install required, thanks to the bundled single-file `.mjs` distribution
2. **Platform detection** - the CLI shows a spinner and checks which supported coding agent CLIs are on your `$PATH`
3. **Parallel checks** - for each detected platform, it checks whether maestria is installed and what version is available
4. **Portable artifact staging** - `plugin validate` checks a directory without writing, while `plugin install` fetches or copies a validated package
5. **Action** - install, update, configure per-agent models, or inspect as needed

All commands support `--json` for script consumption. Runtime platform commands also support `--quiet` to suppress spinner animations for CI environments.
