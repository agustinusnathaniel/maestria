The maestria CLI runs on Node.js 22.12 or later. You do not need to install it: use npx or another package runner to invoke it from npm.

## Quick Start

### Check Your Platforms

<AllPackageManagers type="dlx" pkg="maestria@latest" args="status" />

This checks which supported coding-agent CLIs are on your PATH and reports whether Maestria is installed for each one. With no command, maestria defaults to status.

### Install a Runtime Integration

Install all detected platforms:

<AllPackageManagers type="dlx" pkg="maestria@latest" args="install --all" />

Or select one platform:

<AllPackageManagers type="dlx" pkg="maestria@latest" args="install opencode" />

Replace opencode with the platform ID you want. The [command reference](/cli/commands/#install) lists every supported ID and the native installation path behind it.

### Stage a Portable Agent Plugin

Use the plugin namespace when the client supports Agent Plugins v1:

<AllPackageManagers type="dlx" pkg="maestria@latest" args="plugin install" />

The CLI validates the package, stages it, and prints its directory. Give that directory to the client's own plugin installer or local-plugin setting. The client controls activation, permissions, trust, and session behavior.

For a local package:

```bash
npx maestria plugin validate /path/to/plugin
npx maestria plugin install /path/to/plugin --destination ./staged-plugin
```

### Update an Integration

Update all installed integrations:

<AllPackageManagers type="dlx" pkg="maestria@latest" args="update --all" />

To update one platform or pin a version:

```bash
npx maestria update opencode
npx maestria update opencode --version 0.5.0
```

### Configure Specialist Models

Assign a model to a specialist when the platform supports per-agent configuration:

<AllPackageManagers
  type="dlx"
  pkg="maestria@latest"
  args="configure pi --global --quiet --set builder=opencode-go/deepseek-v4-flash"
/>

Per-agent models are supported on OpenCode, Codex CLI, Cursor, Pi, and Oh My Pi. See the [configure reference](/cli/commands/#configure) for supported platforms and reset syntax.

## Prerequisites

- Node.js 22.12 or later
- npm on PATH when plugin install fetches a package from npm
- The target platform installed before Maestria can detect or install its integration
- An Agent Plugins v1 client for the portable package path

The CLI detects runtime platforms by their executable:

| Platform     | Executable            |
| ------------ | --------------------- |
| OpenCode     | opencode              |
| Pi           | pi                    |
| Oh My Pi     | omp                   |
| Prime Agent  | prime-agent           |
| Kimi Code    | kimi                  |
| Hermes Agent | hermes                |
| Claude Code  | claude                |
| Codex CLI    | codex                 |
| Cursor       | agent or cursor-agent |
