The maestria CLI runs on Node.js 22.12 or later. You do not need to install it: invoke it with npx or another package runner.

## Quick Start

### Check Your Platforms

<AllPackageManagers type="dlx" pkg="maestria@latest" args="status" />

This checks which supported coding-agent CLIs are on your PATH and whether maestria is installed for each one. With no command, maestria defaults to status.

### Install a Host Integration

Install all detected platforms:

<AllPackageManagers type="dlx" pkg="maestria@latest" args="install --all" />

Or select one platform:

<AllPackageManagers type="dlx" pkg="maestria@latest" args="install opencode" />

Replace opencode with the platform ID you want. The [command reference](/cli/commands/#install) lists every supported ID.

### Stage a Portable Agent Plugin

Use the plugin namespace when the client supports Agent Plugins v1:

<AllPackageManagers type="dlx" pkg="maestria@latest" args="plugin install" />

The CLI validates the package, stages it, and prints its directory for the client's own plugin installer or local-plugin setting. Portable discovery supplies the seven skills (handoff, iteration-limits, create-pull-request, docs-update, diagnose, recon, architecture-plan); full methodology uses the selected host's native resources. The client controls activation, permissions, trust, and session behavior.

For a local package:

<AllPackageManagers type="dlx" pkg="maestria@latest" args="plugin validate /path/to/plugin" />
<AllPackageManagers
  type="dlx"
  pkg="maestria@latest"
  args="plugin install /path/to/plugin --destination ./staged-plugin"
/>

### Update an Integration

Update all installed integrations:

<AllPackageManagers type="dlx" pkg="maestria@latest" args="update --all" />

To update one platform or pin a version:

<AllPackageManagers type="dlx" pkg="maestria@latest" args="update opencode" />
<AllPackageManagers type="dlx" pkg="maestria@latest" args="update opencode --version <version>" />

### Configure the Reviewer Model

Assign a model to the reviewer when the platform supports per-agent configuration:

<AllPackageManagers
  type="dlx"
  pkg="maestria@latest"
  args="configure pi --global --quiet --set reviewer=opencode-go/deepseek-v4-flash"
/>

See the [configure reference](/cli/commands/#configure) for supported platforms and reset syntax.

### Skill Setup

Check methodology skill state without changing anything:

<AllPackageManagers type="dlx" pkg="maestria@latest" args="doctor" />

This reports the skill record path, per-platform plugin state, recorded selections, and observed skills with next steps. See the [doctor reference](/cli/commands/#doctor).

## Prerequisites

- Node.js 22.12 or later
- npm on PATH when plugin install fetches a package from npm
- The target platform installed before maestria can detect or install its integration
- An Agent Plugins v1 client for the portable package path

The CLI detects runtime platforms by their executable. Kimi Code is also detected from its plugin registry or `config.toml`, and Cursor from `~/.cursor` only when neither `cursor-agent` nor `agent` is on `PATH`; a bare `agent` binary counts as Cursor only when its `--version` output names Cursor.

| Platform     | Executable            |
| ------------ | --------------------- |
| OpenCode     | opencode              |
| Pi           | pi                    |
| Oh My Pi     | omp                   |
| Kimi Code    | kimi                  |
| Hermes Agent | hermes                |
| Claude Code  | claude                |
| Codex CLI    | codex                 |
| Cursor       | agent or cursor-agent |
