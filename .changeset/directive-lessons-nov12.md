Directive refinements from observed failures. Agents read environment variables by name instead of dumping them all. When you challenge a claim ("you sure?", "cmiiw"), they read it against your whole request and re-check the sources, change the answer only on new evidence they can name, and otherwise keep it and say what they re-checked; the rule for acting on an uncheckable precondition is removed. Milestone reports state the choices made for you and why, and agents ask you to check something only with a screenshot or a link they tested. In the method skills, a rare guard case whose worst case is lost or wrong user data, lost access, or an untraceable failure counts as real; visual evidence for a shared layout or component covers every screen that mounts it or a stated sample; and a rewritten docs page is compared with the old version so nothing that is not history is dropped.
