Add `@maestria/deepseek`, a DeepSeek Harness bundle with a `maestria` agent preset: the orchestrator persona, global rules for every agent and delegated child, one delegation tool per specialist with host-enforced tool filters for the read-only and design roles, and the workflow-mode and methodology skills. `maestria install deepseek` installs it into the `web` profile with `dsh plugin add`.
