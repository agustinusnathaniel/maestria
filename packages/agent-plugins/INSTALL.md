# Install the consolidated plugin

Select `packages/agent-plugins/` for Git and local loaders; the package root is directly installable.

Run `maestria install <host>` for managed hosts: claude-code, cursor, codex, kimi-code, omp, or hermes. Devin and ZCode use their own host installers with this package root.

See https://maestria.sznm.dev/agent-plugins/installation/ for per-host steps and https://maestria.sznm.dev/agent-plugins/compatibility/ for support boundaries.
