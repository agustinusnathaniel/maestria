## ZCode Integration

The overlay explicitly selects the root native agent Markdown files and `commands/fein.md`, `commands/sonar.md`, and `commands/blitz.md`. Agents embed complete role and policy; commands embed the complete mode, router, and policy. Utility skills remain under root `skills/`. Use the native agent and command controls exposed by ZCode and carry a complete task handoff. Root profiles do not assert a universal permission mechanism.

See [ZCode plugins](https://zcode.z.ai/en/docs/plugin).
